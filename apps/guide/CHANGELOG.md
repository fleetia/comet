### Patch Changes

- 0996a9d: 시간성 알림의 대기와 집중 타이머 알림 안내를 개선하고 macOS 화면 잠금·꺼짐과 위젯 입력 중 자동 잡담을 쉬어요. 기념일 축하가 표시되지 않을 때 재시도 간격을 두고 같은 날의 축하를 차례로 표시해요.
- d1a75f3: 시계와 날씨 열기, 바탕화면 위젯의 창 동작과 키보드 접근을 정리해요. 음악 연결 권한과 조용한 시간의 상태를 표시하고 위젯 조작과 알림 안내를 개선해요. 음악 상태의 불필요한 갱신을 줄이고 열린 메모의 초안을 확인한 뒤 삭제해요.
- 0a5198f: 위젯과 집중 타이머의 동작 이름과 알림 안내를 통일하고 아이콘 버튼에 설명을 더해요.
- 645daea: 위젯과 다이어리의 표시를 통일하고 안내서를 현재 사용 방법에 맞춰 정리해요.
- 1db00a4: 빠른 실행에서 다이어리와 AI 위젯을 찾고 바탕화면 위젯을 편집할 수 있어요. 친구를 칩으로 지정하고 Shift+Enter로 할 일을 적을 수 있어요. 음악 창을 열 때 Spotify를 함께 열지 선택할 수 있고, 트레이의 위젯 메뉴를 하루 도구·생활 정보·놀이로 묶어 살펴볼 수 있어요. 음악 연결 안내도 더 쉽게 확인할 수 있어요.
- daef9eb: 도구 창의 위치와 집중 타이머의 접힘 상태를 기억하고 화면 안에 맞춰 열어요. 도구 창의 오류 표시와 처리 중 조작, 집중 타이머의 자동 높이 맞춤도 개선했어요.
- 46d3a83: 바탕화면 위젯의 위치와 모니터 복원, 자동 배치와 모아두기 상태 저장을 개선했어요.
  여러 모니터가 맞닿은 곳에서 바탕화면 장난감과 작은 펫의 이동 경계를 개선했어요.
- 5cecaac: 바탕화면 위젯 편집과 모아두기의 키보드 조작, 접근성 안내와 오류 복구를 개선했어요.
  모아두기 꾸미기를 바로 미리 보고 자유 배치 위젯을 편집 패널에서 선택하고 이동할 수 있어요.
- 1c382a4: 바탕화면 위젯에서 오늘 할 일과 일정 날짜를 더 분명하게 보여 주고, 캘린더와 여행 정보를 불러오지 못했을 때 확인과 재시도를 안내합니다. 음악과 준비 봉투의 빈 상태를 다듬고, 위젯 편집에서 이미지 제거와 되돌리기 범위를 안내하며 그린 모양을 안전하게 저장합니다. 위젯의 투명한 바깥 영역을 클릭할 수 있게 하고, 모아두기에서 창 열기와 설정 아이콘도 구분합니다.

  모양 저장 실패 후 초기화해도 편집을 끝낼 수 있도록 하고, 투명 영역의 클릭 통과를 유지합니다. 캘린더 칩의 날짜를 짧게 표시하고 여행 조회 실패를 칩에도 알립니다.

- 6c644d7: 일정과 여행 알림의 전달과 열기 동작을 개선하고, 바깥 알림 소리를 설정할 수 있어요. 복귀할 때 집중에 연결한 일정의 시작 임박 문구도 정확하게 표시해요.
- a314e71: 캘린더 연결 실패와 재인증을 더 쉽게 해결하고, 절전 복귀 후 날씨와 캘린더를 다시 확인해요.
- 9d65087: 음악과 날씨의 연결 상태와 권한 안내를 더 정확하게 표시하고 다시 조회 동작을 개선했어요.
- e63bc37: 위젯 목록에서 동작과 바탕화면 상태를 쉽게 확인하고, 삭제한 AI 위젯을 복원할 수 있어요. 바탕화면 설정에서 위젯 편집과 친구 표시, 자동 산책을 관리할 수 있어요.
- cfd5534: 첫 만남에서 말 걸기와 옮기기, 위젯과 빠른 실행을 익히고 자동 시작을 설정할 수 있도록 안내해요. 움직이기 준비 상태와 이어서 할 대화가 없는 상태도 알기 쉽게 보여 줘요.
