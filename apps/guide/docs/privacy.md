## 어디에 저장되나요

설정, 대화와 기억 등은 이 기기에 저장해요. 기본 저장 위치는 다음과 같아요.

- macOS: `~/Library/Application Support/space.starlight.comet`
- Windows: `%APPDATA%\space.starlight.comet`

API 키와 ChatGPT 연결 정보는 기기의 보안 저장소에 저장해요.

## 밖으로 나가는 것

외부 AI를 사용하면 대화와 답변에 필요한 선택된 자료가 해당 AI 제공자에게 전송될 수 있어요. 날씨, 캘린더, 음악 연결을 사용할 때도 해당 기능에 필요한 정보가 연결된 서비스로 오갈 수 있어요.

## 사용 통계

사용 통계는 기본으로 켜져 있어요. 설정 → 일반 → 데이터의 **사용 통계 보내기**에서 끌 수 있어요.

앱 버전과 OS, 선택한 AI 종류, 기능 사용, AI 요청의 성공 여부와 응답 시간, 비정상 종료 및 오류 정보를 보내요. 오류 정보에는 정리한 오류 문구와 오류가 발생한 위치가 포함될 수 있어요. 문구에서 경로와 이메일 형태는 지우고 100자까지 보내지만 다른 모든 내용이 제거된다고 보장하지는 않아요. 보안 저장소 오류에는 오류 종류와 Windows 오류 번호가 포함될 수 있어요.

## 지우기와 초기화

기억은 설정 → 친구들에서 보고 지울 수 있어요. 함께 지내는 구성에서 친구를 빼도 그 친구의 기록과 기억, 친밀도는 남아요.

설정 → 일반 → 데이터에서 모두 지우고 초기화하면 설정, 대화, 기억, 단어장, 위젯, API 키와 ChatGPT 연결, 내려받은 모델이 지워지고 별꼬리만 남아요. 앱이 다시 시작되며 되돌릴 수 없어요.
