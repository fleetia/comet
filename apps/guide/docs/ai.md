## AI가 꼭 필요한가요

AI는 선택 사항이에요. AI 없이도 인사·단어장·대화팩과 위젯을 쓸 수 있어요. 자유롭게 AI와 대화하고 싶다면 설정 → AI 연결에서 대화에 쓸 AI를 골라요.

AI를 고르지 않았거나 준비되지 않았다면 AI 없이 쓸 수 있어요. AI를 골라도 내려받기·연결·키 입력이 남아 있다면 준비가 필요해요. 준비를 마치면 AI와 대화할 수 있어요.

## 어떤 걸 고를까요

| 선택 | 준비할 것 | 요금 |
| --- | --- | --- |
| Apple 온디바이스 AI | 지원하는 Mac과 Apple Intelligence | 무료 |
| 이 기기의 모델 | 모델을 저장할 공간과 내려받을 인터넷 연결 | 무료 |
| ChatGPT | Plus 또는 Pro 플랜 계정 | 해당 플랜 요금 |
| Claude·Gemini·GLM | 해당 서비스의 API 키 | 서비스 이용 요금 |
| 사용자 지정 API | 서비스 주소와 필요한 API 키, 모델 이름 | 서비스에 따라 다름 |

macOS에서는 Apple 온디바이스 AI를 추천해요. 내려받지 않고 바로 쓸 수 있어요. 지원하지 않는 Mac이면 이 기기의 모델(2.7GB, 무료)을 써요. Windows에서는 ChatGPT를 추천해요. Plus·Pro 계정이 있으면 가장 빠르고, 없으면 이 기기의 모델(2.7GB, 무료)을 써요. 외부 서비스의 요금과 사용 조건은 해당 서비스에서 확인해 주세요.

## Apple 온디바이스 AI

macOS 26 이상에서 쓸 수 있어요. 시스템 설정 → Apple Intelligence 및 Siri에서 Apple Intelligence를 켜 주세요. 한국어를 지원하며 응답 품질은 아직 평가 중이에요.

## 이 기기의 모델

기본 모델은 약 2.7GB예요. 설정 → AI 연결에서 이 기기의 모델을 골라 내려받아요. 가지고 있는 GGUF 모델 파일을 직접 지정할 수도 있어요.

## ChatGPT

설정 → AI 연결에서 ChatGPT를 골라 연결해요. Plus·Pro 플랜이 필요해요. 연결이 끊기거나 플랜을 쓸 수 없다는 안내가 나오면 계정과 플랜을 확인해 주세요. 연결을 끊거나 다른 계정으로 바꾸는 것도 같은 화면에서 할 수 있어요.

카드에 **연결 필요**가 보이면 계정을 연결하고, **브라우저에서 연결 중**이면 브라우저에서 연결을 마쳐 주세요. **연결됨**은 계정 연결이 된 상태예요. 연결됐더라도 플랜을 쓸 수 없다는 안내가 있다면 플랜을 확인하거나 이 기기의 모델을 쓸 수 있어요.

## Claude·Gemini·GLM·사용자 지정 API

각 서비스에서 API 키를 받은 뒤 설정 → AI 연결에 입력하고 모델을 골라요. 사용자 지정 API는 주소와 모델 이름도 확인해요. 이용 요금은 각 서비스에 내요.

## 무엇이 어디로 가나요

외부 AI를 고르면 대화와 답변에 필요한 자료가 해당 제공자에게 전송될 수 있어요. 자세한 내용은 [데이터와 개인정보](privacy.md)를 보세요.
