## AI가 답하지 않아요

> 대화에 쓸 AI를 아직 고르지 않았어요. 설정 → AI 연결에서 골라 주세요.

AI를 고르지 않았거나 준비되지 않았을 때는 설정 → AI 연결에서 사용할 AI를 골라 준비해 주세요.

> API 키가 없어요. 설정 → AI 연결에서 넣어 주세요.

API 키를 사용하는 AI라면 해당 서비스의 키를 입력해 주세요.

> ChatGPT 연결이 끊겼거나 이 계정은 플랜을 쓸 수 없어요(Plus·Pro만 가능). 설정 → AI 연결에서 확인해 주세요.

연결과 플랜을 확인하고 필요하면 다시 연결해 주세요. Apple 온디바이스 AI가 준비 중이라면 기기의 Apple Intelligence 상태를 확인해 주세요.

## 모델을 내려받지 못해요

> 모델 내려받기 서버(Hugging Face)에 연결할 수 없어요.

> 네트워크나 회사 방화벽이 huggingface.co를 막고 있을 수 있어요.

네트워크와 저장 공간을 확인하고 다시 시도해 주세요. 중단된 내려받기는 **이어 받기**를 고를 수 있어요.

> 모델 저장 실패. 디스크 공간을 확인해 주세요.

저장 공간을 확보한 뒤 다시 시도해 주세요.

> 모델 파일을 찾지 못했어요. 설정 → AI 연결에서 파일 위치를 확인해 주세요.

직접 지정한 파일을 옮겼거나 지웠다면 파일 위치를 다시 확인해 주세요.

## 친구가 조용해요

자동 잡담이 쉬는 중인지, 설정 → 대화 → 조용한 시간에 해당하는지 확인해요. 집중 중이거나 본체가 숨겨져 있어도 자동 대사를 기다려요. 특정 위젯 반응이 없다면 설정 → 위젯에서 **캐릭터 반응**을 확인해 주세요.

## 알림이 안 와요

기기의 알림 권한과 해당 위젯의 알림 설정을 확인해 주세요.

알림 권한이 꺼져 있으면 해당 위젯 설정의 **시스템 설정 열기**로 기기 설정을 열 수 있어요.

> 꺼짐 · 시스템 설정 → 알림에서 켜요

macOS에서는 시스템 설정 → 알림에서 comet을 허용해 주세요.

> 꺼짐 · Windows 설정 → 시스템 → 알림에서 켜요

Windows에서는 Windows 설정 → 시스템 → 알림에서 확인해 주세요.

## 연결이 안 돼요

캘린더는 설정 → 위젯 → 캘린더에서 연결을 확인해요.

> Spotify 연결이 필요해요. 설정 → 위젯 → 음악 앱 연결에서 연결해 주세요.

음악 연결 상태를 확인해 주세요.

> 정리 파일이 충돌해 저장하지 않았어요. 파일을 확인한 뒤 설정 → 일반 → Ex-brain에서 다시 시도해 주세요.

Ex-brain 파일이 다른 곳에서 바뀌었다면 내용을 확인한 뒤 다시 시도해 주세요.

## 업데이트와 설치

설정 → 일반 → comet 업데이트에서 업데이트를 확인할 수 있어요. 자동 시작은 설정 → 일반 → 시작과 종료와 기기의 로그인 항목을 확인해 주세요.

## 그래도 안 되면

안내서가 열리지 않으면 설정 → 일반 → 안내서에서 **경로 복사**를 눌러 경로를 복사한 뒤 브라우저 주소창에 붙여 넣어 주세요.

문제가 계속되면 [GitHub Issues](https://github.com/fleetia/comet/issues) 또는 dev@star-light.space로 알려 주세요.
