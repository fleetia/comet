## 화면과 본체

| 말 | 뜻 |
| --- | --- |
| 본체 | 바탕화면에 머무는 친구의 그림이에요. |
| 말풍선 | 본체 옆에 잠깐 나타나는 대사와 입력 영역이에요. |
| 함께하기 궤도 | 본체를 누르면 나오는 상황별 메뉴예요. |
| 보조 창 | 설정·위젯·여행·다이어리처럼 따로 여는 창이에요. |
| 설정 | 친구들·대화·바탕화면·위젯·AI 연결·일반 탭에서 comet을 바꾸는 곳이에요. |
| 트레이 | 기기의 트레이 아이콘에서 여는 메뉴예요. |
| 빠른 실행 | 단축키로 여는 검색과 명령 창이에요. |
| 안내서 | comet의 사용 방법을 읽는 페이지예요. 기본 브라우저에서 열려요. |
| 튜토리얼 | 친구가 진행하는 첫 만남 이야기예요. |
| 숨기기 / 표시 | 본체를 바탕화면에서 감추거나 다시 보여 줘요. |
| 종료 | 앱을 끝내요. |

## 친구와 대사

| 말 | 뜻 |
| --- | --- |
| 친구 | 나와 함께 지내는 캐릭터예요. |
| 함께 지내는 친구 | 지금 바탕화면에 머무는 친구예요. |
| 찾아오는 친구 | 이야기나 초대로 잠깐 등장하는 친구예요. |
| 캐릭터 팩 | 친구의 그림·대사·관계·이야기를 담은 묶음이에요. |
| 대화팩 | 시간·날씨·위젯 상태에 맞는 대본 묶음이에요. |
| 단어장 | 입력 키워드와 내가 등록한 대사를 잇는 개인 사전이에요. |
| 등록 이야기 | 친구가 제안하고 수락이나 거절을 거쳐 마무리하는 이야기예요. |
| 장을 이어 가는 이야기 | 장과 갈래를 따라 진행하는 등록 이야기예요. |
| 친구가 제안하는 짧은 이야기 | 제안·수락·거절·마무리로 이뤄진 등록 이야기예요. |
| 장 | 이야기의 한 묶음이자 이어서 하기의 단위예요. |
| 이어지는 곳 | 한 장에서 다음으로 가는 갈래예요. |
| 인사 | 시작하거나 돌아왔을 때 친구가 먼저 하는 말이에요. |
| 자동 잡담 | 친구가 스스로 말을 거는 기능이에요. |
| 쉬기 | 자동 잡담을 잠시 멈춰요. |
| 조용한 시간 | 정한 시간대에 자동 대화를 쉬어요. |
| 집중 시간 | 집중 타이머가 집중 중일 때 대화를 제한해요. |
| 수면 | 본체 메뉴로 친구를 재워요. 앱을 다시 시작하면 깨어나요. |
| 기억 | 친구가 대화에서 추출해 저장한 나에 관한 사실이에요. |
| 친밀도 | 친구마다 따로 있는 관계 수치예요. |
| 원문 | 실제로 오간 대사 기록이에요. |
| 지금 기분 | 친밀도와 별도로 움직이는 친구의 짧은 상태예요. |
| 함께한 추억 | 첫 만남처럼 나와 친구가 함께 겪은 일이에요. |
| 함께한 기록 | 친구 상세에서 함께한 일수·추억 수·교감 횟수를 보여 주는 줄이에요. 다이어리에도 같은 이름의 영역이 있어요. |
| 답변 뒤 이어서 할 말 | AI 답변 뒤에 고를 수 있는 짧은 말이에요. |
| 지난 기록 회상 | 지난 다이어리 기록을 꺼내 이야기하는 자동 잡담이에요. |
| 지금 하는 앱 눈치채기 | Windows에서 켜면 쓰는 앱에 관해 한마디 하는 기능이에요. |

## 위젯과 기록

| 말 | 뜻 |
| --- | --- |
| 위젯 | 메모·집중 타이머·날씨처럼 함께 쓰는 도구예요. |
| 공식 위젯 | comet이 제공하는 위젯이에요. |
| AI 위젯 | 대화로 만든 위젯이에요. |
| 캐릭터 반응 | 위젯의 이벤트와 상태에 친구가 말풍선으로 반응할지 정해요. |
| 이미지 | 고른 이미지나 짧은 영상을 바탕화면에 띄우는 공식 위젯이에요. |
| 바깥 알림 | 다른 앱이나 스크립트에서 보낸 글을 친구가 전하는 공식 위젯이에요. |
| 다음 집중 | 집중 타이머에서 다음에 할 집중을 모아 둔 목록이에요. |
| 연속 모드 | 휴식이 끝나면 다음 집중을 바로 시작하는 설정이에요. |
| 긴 휴식 | 정한 회차마다 갖는 더 긴 쉬는 시간이에요. |
| 회차 | 긴 휴식 뒤 완료한 집중의 수예요. |
| 다이어리 | 메모·기록·위젯 결과를 모아 보는 보조 창이에요. |
| 메모 | 다이어리에 남기는 한 줄 기록이에요. |
| Ex-brain | 내 Vault를 검색하고 정리하는 연결이에요. |

## AI 연결

| 말 | 뜻 |
| --- | --- |
| AI 연결 | 대화에 쓸 AI를 준비하는 곳이에요. |
| 대화에 쓸 AI | 설정 → AI 연결에서 고르는 AI예요. |
| 이 기기의 모델 | 기기에 내려받아 기기에서 쓰는 모델이에요. |
| Apple 온디바이스 AI | 지원하는 Mac에서 쓰는 Apple Intelligence 모델이에요. |
| ChatGPT | 계정을 연결해 사용하는 AI예요. |
| Claude / Gemini / GLM | API 키로 연결하는 AI예요. |
| 사용자 지정 API | 서비스 주소를 직접 입력해 연결하는 AI예요. |
| 연결 / 연결 끊기 | 외부 계정을 잇거나 연결을 끊어요. |
| 내려받기 | 모델이나 업데이트 파일을 기기에 받아요. |
| 모델 내려받기 서버 | 모델 파일을 받아오는 곳이에요. |
| AI 없음 | AI를 고르지 않았거나 준비되지 않은 상태예요. |
| 준비 필요 | AI를 골랐지만 내려받기·연결·키 입력이 남은 상태예요. |
| 준비됨 | 지금 AI 대화를 할 수 있는 상태예요. |
| AI에게 묻기 | 이번 입력에서 단어장을 건너뛰고 AI에 보내요. |
