## 공식 위젯 22개

공식 위젯은 항상 모두 있어요. 설정 → 위젯에서 찾아 쓸 수 있어요. 여행은 별도 여행 창에서 관리해요. macOS와 Windows의 음악 설정에서는 위젯을 열 때 Spotify를 실행할지도 정할 수 있어요.

도구 창은 마지막 위치를 기억하고, 집중 타이머는 접은 상태도 기억해요. 도구 창 중에서는 접은 집중 타이머만 다른 창 위에 떠 있어요.

시계와 날씨를 열면 바탕화면에 놓인 표시를 앞으로 가져오고, 놓여 있지 않으면 도구 창을 열어요. 설정은 따로 열 수 있어요.

| 묶음 | 위젯 |
| --- | --- |
| 하루 도구 | 할 일, 캘린더, 집중 타이머, 할 일 완료 구슬, 준비 봉투, 시계·기념일, 메모, 이미지 |
| 놀이 상자 | 친구 교감, 작은 승부, 숫자 맞히기·컵 찾기, 낚시, 식물 키우기, 작은 펫, 장난 운세, 공, 종이비행기, 비눗방울 |
| 생활 정보 | 날씨, 음악 정보, 배터리, 바깥 알림 |

## 친구 반응

설정 → 위젯 목록의 **친구 반응**은 위젯의 이벤트나 상태에 친구가 말풍선으로 반응할지 정해요. 꺼도 위젯 기능과 시스템 알림은 그대로예요. 쉬는 동안의 반응은 다시 켠 뒤 몰아서 나오지 않아요. 이미지에는 친구 반응 스위치가 없어요.

## 바탕화면에 꺼내기

바탕화면에 둘 수 있는 위젯은 목록 메뉴에서 **바탕화면에 꺼내기**와 **바탕화면에서 빼기**를 고를 수 있어요. **바탕화면 위젯 편집**의 놓인 위젯 목록에서 선택하거나 뺄 수 있고, 자유 배치에서는 선택한 위젯을 화살표로 옮길 수 있어요. 이미지 위젯은 별도 창으로 움직이고 크기를 바꿔요.

모아두기에서 시계나 날씨를 열면 해당 행이 펼쳐져요. 모아두기가 접힌 캡슐이면 먼저 말풍선이 나타나요. 모아두기에서 숨긴 위젯은 도구 창으로 열어요.

다이어리에서 메모를 지울 때 열린 낱장에 저장하지 않은 내용이 있으면, 삭제를 취소하고 초안을 보존하거나 초안을 버리고 삭제할 수 있어요.

위젯을 빼도 꾸민 모양과 위치는 남아 있어 다시 꺼낼 때 사용할 수 있어요. 연결했던 화면이 없으면 위젯을 보이는 곳에 표시하고, 저장한 위치는 유지해요. 모아두기의 기준 모서리를 다시 고르면 끌어 옮긴 위치가 초기화돼요. 새 위젯과 이미지는 작업 중인 화면에서 다른 위젯과 친구를 피해 자리를 찾아요.

편집 화면의 **되돌리기**는 편집을 시작했을 때의 배치와 모양으로 복원해요. 자유 배치에서 바꾼 색상·글자와 배경 이미지는 복원하지 않아요. 이미지를 제거할 때는 먼저 확인해요.

할 일 요약은 오늘 계획한 일만 세고, 오늘 할 일이 없으면 밀린 일을 알려 줘요. 캘린더나 여행 정보를 불러오지 못하면 확인이 필요하다고 표시해요. 모아두기에서 여행 정보를 다시 불러올 수 있어요. 자유 배치 위젯의 투명한 바깥쪽은 뒤에 있는 바탕화면을 누를 수 있어요.

## 대화로 쓰기

친구에게 할 일이나 메모를 부탁하는 등 대화로 위젯을 쓸 수 있어요. 저장 결과가 확인된 뒤 완료됐는지 확인해 주세요.

## 연결이 필요한 위젯

캘린더와 음악은 사용할 연결을 정하고, 날씨는 지역을 골라요. 설정 → 위젯 → 바깥 알림에서는 **받기 허용**, **시스템 알림 병행**, **시스템 알림 소리**를 정할 수 있어요. 시스템 알림 소리는 기본으로 꺼져 있고, 조용한 시간에는 켜 두어도 소리가 나지 않아요. 시스템 알림을 받으려면 알림 권한도 필요해요.

Google 캘린더를 연결하려면 Google Cloud에서 사용할 클라이언트를 먼저 준비해요.

1. Google Cloud 콘솔에서 프로젝트를 만들거나 선택하고 **Google Calendar API**를 사용 설정해요.
2. Google 인증 플랫폼에서 앱 정보와 대상 사용자를 설정해요. 앱이 테스트 상태라면 연결할 Google 계정을 테스트 사용자로 추가해요.
3. 사용자 인증 정보에서 OAuth 클라이언트 ID를 만들 때 애플리케이션 유형으로 **데스크톱 앱**을 선택해요. 발급된 클라이언트 ID와 클라이언트 보안 비밀을 Comet 연결 화면에 입력해요.
4. 캘린더 ID의 기본값 `primary`는 로그인한 계정의 기본 캘린더를 뜻해요. 다른 캘린더를 보려면 Google 캘린더 웹의 해당 캘린더 설정 → **캘린더 통합**에서 캘린더 ID를 확인해 입력해요.
5. 연결을 누른 뒤 열린 브라우저에서 Google 계정과 캘린더 읽기 권한을 확인하고 승인해요.

## AI 위젯

설정 → 위젯의 실험 기능에서 AI 위젯을 만들거나 가져올 수 있어요. 삭제한 AI 위젯은 보관 목록에서 복원할 수 있으며, 위젯의 정의와 상태, 작성 데이터와 이전 모습이 유지돼요. AI로 고친 뒤에는 **이전 모습으로 되돌리기**를 고를 수 있어요. Apple 온디바이스 AI는 AI 위젯 제작을 지원하지 않아요.
