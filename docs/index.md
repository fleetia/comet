# comet 사양 안내

comet은 나니카·우카가카처럼 바탕화면에 머물며 먼저 말을 걸고 서로 수다를 떠는 작은 친구들이다. 새 설치의 기본 캐릭터는 별꼬리 한 명이고 최대 8명까지 늘릴 수 있으며, 나디르·별꼬리 텍스트팩은 수동으로 가져오는 [추가팩](product/characters.md#나디르별꼬리-추가팩)이다. 자동 수다는 설치·제거할 수 있는 [대화팩](product/talk.md#대화팩과-나만의-대본)이 맡는다. 작은 토이와 생활 도구의 실제 상태를 대화에 연결하고, 선택적으로 LLM을 사용한다. 기본 화면은 작은 본체와 잠깐 나타나는 말풍선이다.

이 문서는 제품 방향과 개발 계약의 입구다. 구현자와 외부 위젯 개발자가 기능의 목적, 데이터의 주인, 행동 범위와 검증 조건을 확인하는 데 사용한다. 2026-09-19 이름·아이콘 계약에 따라 프로젝트·실행 앱·JavaScript 및 Rust 패키지·실행 파일은 소문자 `comet`, Rust 라이브러리는 `comet_lib`로 통일한다. 기존 설치의 데이터·자격 증명·대본은 첫 실행 때 새 Comet 위치와 형식으로 자동 승계한다. 아이콘 기준은 [제품 이름과 아이콘](product/desktop.md#제품-이름과-아이콘), 실제 검증 범위는 [상태표](status.md)를 따른다.

## 사양과 구현 상태

| 표시 | 의미 |
| --- | --- |
| 구현됨 | 현재 소스에 동작이 있다. 0.2 기반, 0.3.0 캐릭터 기능과 이후 공식 위젯 구현을 구분하며, 소스 구현은 최종 패키지 검증 완료를 뜻하지 않는다. 플랫폼별 실제 검증 여부는 별도 확인한다. |
| 확정 · 개발 예정 | 대화에서 합의한 요구사항이다. 현재 앱에서 사용할 수 있다는 뜻이 아니다. |
| 설계 예시 | 계약을 설명하기 위한 이름·형식·시나리오다. 배포된 API나 파일 규격이 아니다. |
| 미정 | 구현 전에 선택하거나 측정해야 한다. 임의의 기본값을 약속하지 않는다. |

2026-09-27 승인한 [말풍선 답장과 대화 묶음](product/conversation.md#말풍선-답장과-대화-묶음)을 소스에 반영했다. 일반 대사 클릭으로 답장을 시작하고 마지막 대사 옆에서 입력하며, 현재 로그·접어두기·종료·이어하기를 구분한다. 화면 계약은 [바탕화면 경험](product/desktop.md#말풍선에서-이어지는-직접-대화), 이번 소스와 실제 실행 검증은 [상태표](status.md#2026-09-27-말풍선-답장과-대화-이어하기)를 따른다.

**공식 위젯 16개와 AI 위젯 제작·수정·JSON 가져오기를 소스에 구현했다.** 2026-09-29 완료 구슬병·기기 소식·맞히기 놀이·낚시·화분·작은 펫을 공식 실행 경로에서 제거하고 기존 데이터는 보존한다. 공식 도구는 동봉 manifest와 공용 Rust 호스트로 실행하며, AI가 만든 JavaScript는 제한된 Worker에서 자체 상태와 화면 노드만 다룬다. 제작·자동화·상태별 대사·내부 ex-brain 계약은 [AI 위젯 제작](widgets/ai-creation.md)을 따른다. 범용 외부 SDK·임의 native 프로그램·원격 패키지 배포는 후속이다. [기존 위젯 검증 기록](VALIDATION-WIDGETS.md)과 [이번 소스의 구현·검증 상태](status.md)를 구분한다.

**공식 위젯 상태·사건을 읽는 `.talk` 대본과 CLI를 구현했다.** 파일 기반 재로딩, 대화팩 설치·제거와 1~8명 대본 재생은 [대본 작성](product/talk.md), 해당 변경의 macOS 실행과 검증 제한은 [대본 검증 기록](VALIDATION-TALK.md)을 따른다. `.talk` 원문 편집은 앱 밖의 별도 talk editor가 맡는다. 새 **상태별 대사** 메뉴는 위젯 조건에 연결된 원문·표정·동작을 편집하는 별도 기능이다.

2026-09-24 [캐릭터 행동과 반응](product/character-reactions.md)은 클릭·잡기·놓기와 지원 위젯 사건에 대사·표정·동작을 연결하고 대사별 동작과 팩 v5를 지원한다. 본체 한 번 클릭은 반응, 우클릭은 메뉴다. 새 소스의 실제 실행 검증은 [상태표](status.md)에서 확인한다.

## 유지할 제품 경계

- A/B는 사용자가 질문하지 않아도 인사하고 수다를 떤다. LLM 설치는 기본 경험의 준비 조건이 아니다.
- 배경이 있는 큰 채팅 창이나 상시 대시보드로 중심 경험을 바꾸지 않는다. 도구와 보조 화면은 필요할 때 연다.
- 키워드 단어장은 모델보다 먼저 처리하고 등록 대사의 본문·공백·줄바꿈·화자 순서를 보존한다.
- 할 일은 계정 없이 comet에 저장한다. 캘린더는 Google Calendar·macOS Apple EventKit·iCalendar 구독으로 읽기 연결하며 외부 일정은 수정하지 않는다. 다른 사용자와 함께하는 할 일 기능과 RSS는 제공하지 않는다.
- 공식 위젯은 사용자가 선택해 설치하고 이후 추가·중지·제거할 수 있게 한다. AI 위젯은 직접 요청·JSON 가져오기 또는 허용한 자동 제작으로 추가한다. 위젯 없이도 본체는 동작하며, 제거가 사용자 작성 데이터를 자동 삭제하지 않는다.
- AI 위젯의 기본 JavaScript runtime은 앱에 포함한다. 임의 외부 package를 자동 설치하지 않으며, 미래 설치 기능은 구체적인 패키지·출처·크기·권한에 대한 사용자 동의를 요구한다.
- 캐릭터를 교체하고 공유할 수 있게 한다. 공유 콘텐츠와 개인 대화·기억·친밀도를 분리하며, 처음에는 텍스트 표정 상자를 유지한다.
- 위젯의 실제 상태·사건·명령·실행 결과를 구분한다. 대사를 했다는 이유로 데이터를 변경하지 않는다.
- 자원 사용, 오류, 오래된 정보, 사용자 데이터 보존을 공통 실행 규칙으로 관리한다.

## 문서의 원본과 변경 방법

저장소의 `docs/`가 사양 원본이고, `wiki/`의 Docusaurus가 이 파일들을 직접 읽어 웹으로 보여 준다. 위키용 사양 사본을 따로 유지하지 않는다. 기존 `PRODUCT.md`는 0.2 기준과 당시 인수 결과를 보존하며, 이후 확장 계약은 주제별 문서에서 관리한다.

요구사항이 바뀌면 해당 주제 문서와 [상태표](status.md)를 함께 갱신한다. 구현 완료 표시는 코드와 검증 근거를 확보한 뒤 변경한다. 과거 검증 기록의 결과를 새 버전의 결과로 재사용하지 않는다.
