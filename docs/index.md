# comet 문서

comet은 바탕화면에 머무는 작은 캐릭터와 잠깐 나타나는 말풍선을 중심으로 하는 데스크톱 앱이다. 이 문서는 사용자에게 보이는 동작과 데이터를 보존하는 경계, 확장 기능과 개발 절차를 설명한다. 설치 파일과 첫 실행 명령은 저장소 루트의 `README.md`에서 시작한다.

모델·API 연결은 선택 사항이다. 새 프로필은 기본 캐릭터의 인사와 이름 질문으로 시작하며, 이름을 저장하면 내장 대사로 자동 잡담을 이어 간다. 설정·다이어리·대화 기록은 필요한 때 여는 보조 화면이다.

| 읽는 목적 | 문서 |
| --- | --- |
| 본체·말풍선, 설정, 자동 동작, 대화와 데이터 보존 | [제품 동작](behavior.md) |
| 캐릭터·대화팩, 공식 위젯, 다이어리·메모, AI 위젯 | [확장 기능](extensions.md) |
| 소스 실행, 검사, 격리된 데스크톱 QA, 릴리스와 위키 | [개발과 검증](development.md) |
| 별도 기기·계정·실제 모델에서 남아 있는 확인 | [미검증 범위](status.md) |

## 문서의 역할

`docs/`가 제품·개발 계약의 원본이며 `wiki/`는 같은 파일을 직접 읽는다. 변경 이력과 특정 빌드의 실행 기록은 Git과 작업 기록에 둔다. [미검증 범위](status.md)는 아직 확인하지 못한 경계와 완료 기준만 관리한다.

화면·명령·저장 형식을 바꾸면 그 기능을 설명하는 문서를 함께 갱신한다. 구현이 있다는 사실과 실제 운영체제·외부 계정·모델에서 확인했다는 사실을 구분하며, 코드에 없는 동작을 문서만으로 지원한다고 선언하지 않는다.
