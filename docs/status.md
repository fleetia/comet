# 구현 상태와 미정 사항

2026-09-15의 소스와 기존 검증 기록을 기준으로 사양의 상태를 구분한다. 0.3.0 캐릭터 기능과 macOS 패키지·네이티브 사용 흐름을 검증했다. 근거와 한계는 [0.3.0 검증 기록](VALIDATION-0.3.0.md)에 있다. `0.2.0 검증 기록`에 적힌 실행 결과는 당시의 macOS 관찰이며, 문서 작성 시 다시 수행한 결과가 아니다.

## 기존 구현

| 범위 | 코드 상태 | 검증 범위 |
| --- | --- | --- |
| 작은 A/B 본체·공용 말풍선·메뉴·입력 | 구현됨 | 기존 macOS 네이티브 관찰 및 컴포넌트 검증 |
| 모델 없는 인사·정기 잡담 | 구현됨 | 기존 macOS에서 인사와 다음 한 차례 정기 장면 관찰 |
| 키워드 단어장 CRUD·원문 재생 | 구현됨 | 기존 단위·컴포넌트·macOS 저장/재시작 관찰 |
| 대화 기록·기억 수정·개별 친밀도 | 구현됨 | 기존 코드 검증과 메시지 보존 확인. 모델의 사실성 보장은 아님 |
| 둘 모두 직접 응답의 단일 생성·A→B 재생 | 구현됨 | 단일 생성 요청·전체 검증·부분 재시도·문맥 보존 테스트, macOS 4B 직접 응답 3회와 표시 순서 확인. 말투의 자연스러움이나 사실성 보장은 아님. [대화 계약](product/conversation.md#둘-모두에게-말하기) |
| Qwen3.5-4B 기본·9B 선택 | 구현됨 | 기존 4B 네이티브 요청 성공. 두 모델의 정량 품질 비교 완료를 뜻하지 않음 |
| llama.cpp 실행기·선택적 외부 API | 구현됨 | 기존 코드·macOS 프로세스 종료 검증. 장시간 자원 사용 실측은 남아 있음 |
| Windows x64 빌드 설정 | 있음 | Windows 네이티브 실행·설치 검증 미완료 |

기존 기능의 수치·동작 기준은 [0.2 제품 사양](PRODUCT.md), 구체적인 관찰과 한계는 [0.2.0 검증 기록](VALIDATION-0.2.0.md)을 따른다.

RSS는 개발 목록에서 제외한다. 투두는 외부 Todoist·TickTick 등의 계정 연결을 전제로 하지 않는다. Google Calendar 쓰기 연결은 첫 캘린더 범위에 포함하지 않는다.

## 구현 전에 정할 사항

| 결정 지점 | 현재 경계 | 결정할 시점 |
| --- | --- | --- |
| 캐릭터 후속 확장 | JSON formatVersion 1·로컬 ID·관계 이전은 소스 구현. 이미지·스킨·원격 업데이트·개인 단어장 캐릭터 한정 UI는 미구현 | 해당 확장 구현 전 |
| 공식 위젯 배포 | 선택 설치는 확정. 동봉 패키지부터 시작하는 방안이며 원격 배포 주소·서명은 미정 | 공식 설치기 구현 전 |
| Rust workspace | 현재 단일 crate. 공통 계약을 실제 공유할 때 workspace·계약 crate 도입 권장 | 별도 Rust 패키지 도입 시 |
| 캘린더 인증과 구독 갱신 | Google 읽기 연결·ICS 구독 방식은 확정. 인증 세부와 갱신 간격은 미정 | 캘린더 연결 구현 전 |
| 반복 투두 편집 | 반복 기능은 포함. 이번 회차/이후 회차/전체 편집과 완료 후 다음 회차 생성 규칙은 미정 | 투두 데이터 모델 확정 전 |
| 일정과 투두의 연결 | 개별 일정 회차와 사용자 작성 준비물을 구분·보존 | 준비 봉투 구현 전 |
| 알림 빈도·유효기간·조용한 시간 | 중복·폭주 방지 및 숨김·일시정지 존중은 확정. 구체 수치는 미정 | 통합 스케줄러 구현 전 |
| Widget SDK 형식 | 상태·사건·명령·결과와 권한 경계는 확정. 공개 필드명·호환 정책은 설계 중 | 첫 외부 패키지 공개 전 |
| 외부 로직 실행 | 기본 화면과 후속 커스텀 화면 방향은 확정. 숨겨진 임의 코드의 상주 실행은 보장하지 않음 | 외부 SDK 시제품 단계 |
| 자원 예산 | 가벼운 기본 상주·화면 해제·공통 예약 실행 원칙은 확정. MB/CPU 목표는 실측 후 설정 | 각 구현 단계의 성능 검증 |
| 앱 이름과 데이터 식별자 | 프로젝트는 Comet, 실행 앱 이름은 Nanika Box 유지, 캐릭터 기능은 0.3.0 | 별도의 이름 변경·데이터 이전 작업 시 |

마켓플레이스, 자동 업데이트 서비스, 네이티브·WASM 확장 실행기와 공개 위키 호스팅은 이 문서 작성의 구현 범위에 포함하지 않는다.
