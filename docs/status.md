# 미검증 범위

소스 구현과 자동 검사만으로 완료를 판단할 수 없는 범위다. 이 페이지에는 남은 확인과 완료 기준만 적고 변경 이력·테스트 개수·특정 QA 빌드의 관찰은 작업 기록에 남긴다.

## 현재 소스의 검사와 데스크톱 빌드

작성 시험·NPC 포함 팩 공유·이동 진단을 포함한 현재 소스로 별도 식별자의 QA 앱을 새로 빌드하고 서명·실행·변경 동작을 확인해야 한다. 실행 파일과 소스의 대응, 원문·설정·팩·자산·기준점 및 SQLite 보존도 다시 대조한다. 새 앱의 정상 실행을 확인한 뒤 오래된 배포 산출물을 정리한다.

프런트엔드 전체 검사에서 시간 제한으로 실패한 `CharacterMemory`와 `ReactionEditor` 사례를 재확인하고 현재 소스의 타입·lint·Clippy·문서 검사를 마쳐야 한다. 부분 검사나 이전 앱의 성공 결과를 전체 완료로 사용하지 않는다.

## 작성 시험과 팩 공유

캐릭터 관리자에서 작성 시험으로 아직 저장하지 않은 인물별 모션 자산을 전달하는 연결이 남아 있다. 임시 다화자 재생이 현재 초안의 표정·모션·원문을 사용하는지, 같은 자산의 유지와 변경한 자산의 재생 무효화를 실제 편집 화면에서 확인한다.

NPC·방향별 관계·이야기 시험의 조건·차단 이유·출처·화자·전이 전후가 실제 실행 규칙과 일치하는지 확인한다. 초안·대상·조건 변경, 접기·닫기·unmount 뒤 결과와 재생이 남지 않아야 한다. 시험은 실제 대화·기억·친밀도·flags·간식·팩·NPC 창을 바꾸지 않아야 하며, 모델이 필요한 경우에는 실행하지 않았음을 표시해야 한다.

상주 인물과 NPC가 섞인 팩을 실제 UI에서 전체 내보내기·재가져오기하고 역할·입퇴장·관계 원문·이야기·조건부 지식·자산 참조를 대조한다. 구형 팩 왕복과 새 로컬 ID의 연결, 설치 뒤 상주 인물만 함께 지내기에 추가되는 동작도 포함한다. NPC 하나의 복제 성공을 전체 이야기팩 왕복으로 사용하지 않는다.

## 기능 재연결과 저장 경계

날짜 없는 다이어리·수집함 입력, 위젯 제작창의 create/import 재진입·초안 분리·생성 취소, 저장한 범위의 Ex-brain 검색 시험을 현재 앱에서 확인한다. A→B→A 선택 전환의 늦은 응답, 외부 원문 보존, 두 창의 revision 충돌과 닫기 초안 보존도 직접 조작한다.

통합 보내기·재시도에서 등록 화자 부재를 설정 오류로 표시하고 원문을 AI 답변으로 대체하지 않는지 확인한다. 과거 `ai_only` 선택·미완료 등록 원문의 복구, 미표시·취소·중복 완료 효과의 0·0·1회와 정의 저장·숨김·집중·참가자 변경 뒤 늦은 발화·효과 차단도 현재 앱에서 확인해야 한다.

## Windows 실제 사용

현재 소스의 Windows 앱에서 설치·공식 updater·이전 프로세스 종료와 자동 재시작을 확인해야 한다. 다중 모니터·DPI, 투명 영역 클릭 통과, 본체·메모·위젯의 위치 복원, 트레이·단축키·로그인 자동 실행도 실제 조작이 필요하다.

이번 변경의 Windows 실기 검증은 사용자가 추후 수행한다. Ctrl+드래그와 메뉴의 움직이기를 각각 확인하고, 일반 교감에서 위치가 바뀌지 않는지, 정상 드롭만 재시작 뒤 복원되는지, Escape·숨김 취소가 기준점을 유지하는지 확인한다. 단축키 적용 실패·중복 등록·기존 키 복구도 실제 OS에서 확인한다.

첫 이름 질문, 설정 저장, 조용한 시간, 집중 중 대화 제한과 초안 보존, 절전·복귀, 대화팩·모델 준비와 앱 종료까지 이어지는 경로를 대상 기기에서 확인한다. 낮은 메모리의 CPU 환경에서 장시간 자원 사용과 취소·종료도 별도 측정한다. macOS 결과나 Windows CI의 compile 성공은 이 확인을 대신하지 않는다.

집중 타이머의 다이얼·숫자 전환, 창 축소·확장, 일정 등록·연결, 집중 기록·노트 원본 편집과 OS 알림·소리도 대상 기기에서 확인한다.

완료하려면 실행한 소스·설치 파일·OS·기기를 식별하고 각 경로의 조작과 결과를 남겨야 한다. 설치 파일 직접 실행과 앱 내부 updater는 구분한다.

## macOS의 남은 직접 조작

통합 보내기와 본체 교감의 현재 소스에서 Cmd+드래그와 메뉴의 움직이기로 집기·이동 중 매달림·정지·착지와 정상 드롭 저장을 확인해야 한다. 자동 조작으로는 실제 OS 이동 시작을 확인하지 못했으므로 눌러 유지한 실제 마우스 이동으로 시작·종료를 확인한다. 볼을 누른 동안의 유지 자세, 이동 중 Escape·포커스 이탈·숨김의 취소, 배율·모니터 변경과 상주 순서 변경 뒤 로컬 캐릭터 ID의 기준점 복원도 실제 조작이 남아 있다. 제스처 회귀 검사와 이전 QA 빌드의 실행 결과는 현재 소스의 확인을 대신하지 않는다.

집중 중 무언 교감, 실제 음악 재생에 따른 자세, 산책·가장자리 동작의 생활 반경과 기준점 불변을 현재 앱에서 확인해야 한다. 중단 뒤 밀린 동작이 재생되지 않는지, 빼꼼 자세가 계속 잡히는지, OS의 동작 줄이기 설정을 따르는지도 포함한다.

NPC·등록 이야기·관계 대화는 역할 편집·내보내기와 재가져오기, 부재 화자 오류, 재시도의 원문 복구와 중복 완료 방지를 실제 앱에서 추가 확인해야 한다. 정의 변경·숨김·집중 중 오래된 참가자와 결과가 반영되지 않는지도 직접 조작한다. 과거 단계의 앱과 순수 시험의 성공을 현재 재생 증거로 사용하지 않는다.

집중 시작 순간 재생 중인 대사가 사라지는 동작과 빠른 실행에서의 집중 중 대화 거절, 전역 단축키로 빠른 실행을 여는 동작을 직접 조작으로 확인해야 한다. 진행 중 작업의 취소에 대한 자동 회귀 검사는 이 직접 조작을 대신하지 않는다.

집중 타이머의 공통 일정 알람이 실제 예정 시각에 표시되는지, macOS 알림 권한을 허용한 뒤 OS 배너와 소리가 선택한 설정대로 나오는지 확인한다. 권한 요청 전의 설정 저장과 미리보기는 실제 OS 전달을 대신하지 않는다.

노트 편집 창은 마우스·키보드로 작성과 저장을 확인했지만, 검증 도구의 macOS 접근성 트리에는 입력 요소가 나타나지 않았다. VoiceOver 등 보조기술에서 제목·본문·저장 동작이 노출되는지 직접 확인해야 한다.

## Linux 주간 평가 재확인

Linux 평가에서 관찰한 수집함 접근·저장 실패가 현재 소스에서 해결됐는지는 해당 환경에서 다시 확인해야 한다. 수집함 설치·켜기·조회 복구, 날짜 없는 항목 저장·재열람과 실패 시 입력 보존을 실제 Linux 앱에서 조작한다. macOS 결과와 공통 회귀 검사는 이 확인을 대신하지 않는다.

## 실제 캘린더 계정과 OS 자격 증명

Google 실계정의 OAuth 동의·token 갱신·연결 해제, OS Keychain 읽기·권한·재인증, Apple 개인 캘린더 접근과 원본 색상 동기화는 실제 계정에서 확인해야 한다.

설정 화면이 열리거나 합성 응답이 성공했다는 사실만으로 인증 복구를 완료로 처리하지 않는다. 실제 권한 경계에서 연결하고 수동 갱신이 새로운 조회와 정상 상태로 끝나는지, 해제 후 자격 증명과 작업이 올바르게 정리되는지 확인한다.

## 실제 모델의 대사·기억 품질

응답 JSON의 형식, 단일 응답 성공과 대사의 의미 품질은 별도다. 실제 캐릭터·기억·스토리 프롬프트로 다중 턴 입력을 평가해야 한다. 주체·기억의 귀속, 정정한 취향의 반영, 캐릭터 말투, 다인 대화의 반복·길이, 공개되지 않은 스토리 정보의 보호가 포함된다.

선택한 모델·설정·입력과 실제 출력 원문을 남기고 모델별로 판정한다. 키 없는 로컬 API도 실제 Ollama·LM Studio 서버의 연결부터 응답까지 확인한다. 의미 검색의 정확도와 배포 산출물 검증은 생성 LLM의 응답 성공과 분리한다.

다인 생성은 현재 질문에 직접 답하는지, 각 화자의 말버릇과 방향별 관계를 분리하는지 추가 평가해야 한다. 정보 제한과 JSON 화자 순서를 통과해도 같은 말버릇의 반복, 관계의 주체 혼동, 근거 없는 전제와 한국어 대사에 다른 언어가 섞이는 결과를 의미 품질 통과로 처리하지 않는다.

메모를 연결한 대화에서는 선택한 원문의 행위 주체·작업 상태·미정 사항을 유지하는지, 현재 요청의 역할·언어·길이를 지키는지 실제 모델별로 확인한다. 저장한 재개 지점을 현재의 완료 상태로 오인하거나 작품 속 인물과 캐릭터 화자를 혼동하지 않는지도 포함한다. 원문 전달·저장·재생·취소의 회귀 검사와 합성 API 응답은 이 의미 품질 평가를 대신하지 않는다.

## 갱신 기준

남은 범위가 실제 대상 환경에서 확인되면 이 페이지에서 해당 항목을 줄이거나 제거한다. 새 변경이 이전 확인을 무효화하면 필요한 범위만 다시 적는다. 상세 결과는 작업 기록에서 보존하고 이 페이지를 완료 내역으로 늘리지 않는다.

## 프로그램 전면 사용 시간

집중 타이머의 선택 앱 전면 사용 시간은 Windows 네이티브 API 구현을 포함한다. 실제 기기에서 앱 선택·전환·60초 유휴·잠금/해제·절전/복귀·재시작을 조작하고, 기존 카운트다운 옆 표시 및 저장된 세션 누적값을 대조하는 검증이 남아 있다. macOS와 Linux는 잠금 상태를 신뢰성 있게 확인하는 방법과 실기 검증을 확보하기 전까지 명시적 미지원이다. 자동 검사나 운영체제별 빌드 성공만으로 실제 기기 관측 정확도가 검증된 것으로 보지 않는다.

## ChatGPT와 Ex-brain의 실제 계정·자료 검증

ChatGPT의 실제 계정에서 동의 취소·만료·회전 토큰 갱신·계정 전환·로그아웃을 조작해야 한다. 보안 저장소 거절·실패와 원격 세션 해제를 확인하지 못한 경우의 안내도 실제 OS에서 확인한다. 합성 JWT·세션 회귀 검사는 이 조작을 대신하지 않는다.

강제 종료가 파일 저장 중간에 발생한 경우와 실제 디스크 권한 오류의 복구는 회귀 검사와 별도로 조작한다. Windows와 Linux의 보안 저장소·loopback 로그인·파일 접근 경계는 해당 기기에서 검증한다.

실제 외부 API 모델에 동일한 회의 문서와 할 일 요청을 제공하고 출처 정확성, 결정·미정·완료 구분과 명시적 요청 해석을 평가해야 한다. ChatGPT와 기본 로컬 모델의 짧은 합성 사례를 장문·복수 문서 품질로 확대하지 않는다. 기본 로컬 모델은 정리본을 바탕으로 말할 때 일정의 대상과 제안 상태·말투를 보존하는지 추가 평가한다. 캐릭터 답변의 간결성과 내부 출처 식별자 노출도 줄여야 한다. 연결 성공, 합성 API 응답 또는 JSON 형식 검증을 의미 품질 확인으로 대신하지 않는다.
