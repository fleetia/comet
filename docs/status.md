# 구현 상태와 남은 검증

2026-09-16 작업 소스를 기준으로 **공식 위젯 22개와 선택 설치·추가·중지·제거, `.talk` 파일 대본을 구현했다.** 소스 구현, 자동 테스트, 실제 데스크톱 동작, 외부 계정 인증과 모델 의미 품질을 각각 구분한다. 위젯 변경의 실행 근거는 [위젯 검증 기록](VALIDATION-WIDGETS.md), 별도로 진행한 보조 화면 UI 정리의 범위는 아래에 기록한다.

기존 작은 A/B·내장 인사·단어장·기록·기억·친밀도는 유지한다. 캐릭터 관리·JSON 공유의 0.3.0 검증은 [기존 기록](VALIDATION-0.3.0.md), 0.2 기능과 당시 실측은 [제품 사양](PRODUCT.md)과 [0.2 기록](VALIDATION-0.2.0.md)에 보존한다. 과거의 네이티브 관찰·테스트 수·모델 성능을 새 위젯 결과로 재사용하지 않는다.

## `.talk` 대본 검증

2026-09-16 Rust 라이브러리 172개·CLI 2개·프론트엔드 83개 테스트와 Clippy·doc-test를 통과했다. 기본 대본은 130개 장면, 검증 fixture는 166개, 공개 변수는 109개다. 의미 있는 상태별 범위는 [기본 대본 범위](development/talk-coverage.md)를 따른다.

실제 macOS에서 모델 없이 22개 기본 위젯 상태의 대본, 실제 사건과 외부 조회, 파일 재로딩·오류 복구, 조합·자리 교환, 입력·숨김·일시정지 중단, 재시작 보존과 자연 자동 수다 교대를 확인했다. 실제 장면 기록과 관찰 방법은 [대본 검증 기록](VALIDATION-TALK.md)에 남긴다. Google·음악 계정 연동과 Windows 실행은 이번 검증에 포함하지 않는다. 이 결과를 기존 UI·위젯 검증 기록의 실측으로 소급 적용하지 않는다.

## 보조 화면 UI 검증

2026-09-15 비위젯 UI 변경 전 테스트 28개를 기준으로, 탭 이동·초안 유지·저장 중 입력 차단·삭제 확인·메뉴 복귀 검증을 보강했다. 2026-09-16 최종 확인에서 `src/__tests__`의 6개 파일 33개 테스트, TypeScript·정적 검사·Vite 빌드를 통과했다.

브라우저 미리보기에서는 설정 760×760, 캐릭터 관리 960×760과 좁은 390×844 화면을 확인했다. 설정·단어장·캐릭터 초안 유지, 저장 실패 후 초안 유지, 변경 취소와 키보드 탭 이동을 확인했다. 말풍선의 입력·기록에서 메뉴 복귀, 입력 초안과 일시정지 상태 표시, 본체 112×88도 확인했다. 실제 저장과 파일 공유는 네이티브 앱 기능이므로 이 브라우저 검증으로 증명하지 않는다. 이번 UI 정리에서는 네이티브 설치물을 다시 빌드하거나 실행하지 않았다.

## 위젯 UI 검증

2026-09-16 위젯 디자인 정리 후 전체 프론트엔드 13개 파일 79개 테스트를 통과했다. 마지막 할 일 설정 요약 보완은 관련 2개 파일 20개 테스트로 다시 확인했다. TypeScript·정적 검사·포맷 검사·Vite 빌드를 통과했다. 관리 탭의 선택 유지, 오류 복구, 수정 취소, 실패 초안 보존과 캘린더 중복 표시를 회귀 검증했다.

브라우저 예시 데이터로 22개 도구를 최소 296×320에서 열어 가로 넘침과 오류 표시가 없는지 확인했다. 관리 화면은 880×760과 최소 560×480, 대표 도구는 360×480에서 확인했다. 할 일의 입력 초점·접힌 기한 오류 복구·선택 설정 요약, 관리 화면의 탭 키보드 이동·설치 선택 유지·확인 필요 필터도 조작했다. Figma에는 관리 화면 두 상태와 대표 도구 배치를 반영했다. 이 검증은 실제 저장·외부 연결·22개 기능의 네이티브 조작을 증명하지 않으며, 위젯 디자인 정리의 최종 소스로 네이티브 앱을 다시 패키징하지 않았다.

## 공통 창 조작 검증

2026-09-16 공통 창 조작 변경은 TypeScript·정적 검사·Vite 빌드와 `cargo check`를 통과했다. 마지막 관련 회귀 검증은 5개 파일 39개 테스트를 통과했으며 제목 드래그와 버튼 분리, 로딩·오류 상태의 닫기, 본체 숨기기와 위젯 닫기 명령을 확인했다. Figma의 기존 설정 화면 헤더에 내부 ×를 반영했다.

별도 프로필 `space.starlight.comet.window-qa`의 macOS 테스트 앱을 빌드하고 `codesign --verify --deep --strict`를 통과했다. 설정·캐릭터 관리·위젯 관리·메모 위젯의 네이티브 제목 표시줄 제거와 내부 × 닫기, 본체 ×의 숨기기와 기존 말풍선 닫기를 실제 앱에서 확인했다. 최신 빌드의 메모 창에서 제목 드래그를 실행하고 더블클릭 후에도 360×480 크기가 유지되는 것을 확인했다. 위젯을 닫고 관리 화면으로 돌아왔을 때 설치·사용 상태가 유지됐다. 이 확인은 별도 테스트 앱의 결과이며 기존 실행 앱 교체, Windows·다중 모니터 검증이나 모델 의미 품질 검증을 포함하지 않는다.

공통 헤더의 후속 변경은 드래그 범위를 창 `(0, 0)`부터 보이는 헤더 하단까지 확장했다. 원점·바깥 여백, 본문·스크롤바 경계, 입력과 열린 대화상자 제외를 포함한 관련 4개 파일 31개 테스트와 TypeScript·정적 검사·Vite 빌드를 통과했다. 별도 `space.starlight.comet.drag-qa` macOS 앱을 빌드·서명 검증한 뒤 위젯 관리의 왼쪽 위 여백 `(12, 12)`에서 드래그를 실행하고 본문 탭 전환과 X 닫기가 유지되는 것을 확인했다. 창 이동 좌표는 별도 계측하지 않았으며 기존 실행 앱은 교체하지 않았다.

확장한 여백에도 드래그와 같은 판정으로 `grab` 커서를 적용했다. 조작 요소·본문으로 이동하거나 스크롤·초점 이동·창 이탈이 발생하면 임시 커서 스타일을 해제한다. 이 커서 변경은 관련 2개 파일 10개 테스트와 TypeScript·정적 검사·Vite 빌드를 통과했다. Figma의 공통 헤더 조작 명세에도 반영했으며, 이번 커서 변경의 네이티브 화면 표시는 별도로 검증하지 않았다.

## 아직 구분해야 할 검증

- 전체 자동 테스트·정적 검사·패키징의 최종 결과는 [위젯 검증 기록](VALIDATION-WIDGETS.md)에 기록한다.
- macOS 네이티브 실행 결과는 해당 기록의 관찰 칸에 실제 수행한 범위만 적는다.
- Google 실제 계정 OAuth 동의·token 갱신과 Windows 네이티브 설치·실행은 미검증이다.
- 장시간 CPU·메모리·배터리·다중 모니터·접근성 전수 검증과 모델 대사의 의미 품질은 이번 자동 테스트의 증명 범위가 아니다.
- RSS, Todoist·TickTick 원본 대체, Google Calendar 쓰기, Apple EventKit 직접 연결은 구현 범위에서 제외한다.
