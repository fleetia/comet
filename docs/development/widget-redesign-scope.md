# 위젯 실행 화면 재설계 범위

2026-09-20 사용자는 개별 위젯 실행 창의 내부 UI를 전면 재설계 대상으로 남겼다. 그 뒤 플래너 R2·음악 상세와 가사·낱장 메모·공통 창 구조가 바뀌었다. 이 문서는 그 결정을 취소하거나 현재 화면을 최종 승인하지 않는다. 다음 디자인 작업 전에 각 화면의 이후 승인 범위와 바꿀 흐름을 확인하기 위한 목록이다.

현재 공식 설치 단위는 16개이며, 미설치 수집함이 없는 새 사용자에게는 15개가 보인다. 제거한 여섯 위젯을 복원하거나 별도 SDK·마켓을 설계하는 작업은 이 범위에 포함하지 않는다.

## 현재 가벼운 UI 유지 결정

2026-10-02 사용자는 UI를 새로 만들 계획이므로 우선 가볍게 남기기로 했다. 이번 범위는 기존 기능을 확인하고 사용할 수 있는 필수 조작·설정과 단순한 창 구조를 유지하는 것이다. 공통 footer의 불필요한 테두리는 제거했고 새 기능의 필요한 조작만 추가한다. 전체 화면 재설계·기존 기능 삭제·새 디자인 시스템 도입으로 확대하지 않는다. 이 범위는 확정됐으며 추가 답변을 기다리는 상태가 아니다.

## 공통으로 보존할 계약

- 작은 본체와 일시 말풍선이 중심이며 상시 대시보드로 바꾸지 않는다.
- 설치·켜짐·실행 창 열림·바탕화면 표시를 구별한다.
- 설정은 통합 설정창, 실제 작업은 실행 창에서 수행한다.
- 고정 헤더는 제목과 닫기, 본문은 스크롤, 내용과 독립된 조작만 오른쪽 아래에 둔다. 하단에 별도 테두리·박스를 추가하지 않는다.
- 데이터·원문·초안·반복·취소·revision 경계를 디자인 변경 때문에 초기화하지 않는다.
- Figma를 사용하지 않고 기존 코드와 렌더를 기준으로 검토한다. 실제 지원 데스크톱에서 변경 흐름을 확인하기 전에는 최종 디자인 인수 완료로 표시하지 않는다.

## 향후 전체 UI 재설계 때 정할 것

대상 화면마다 유지/부분 수정/재설계, 바꿀 사용자 흐름, 필요한 빈 상태·오류 상태, 저장 책임과 완료 조건을 선택한다. 현재는 위의 가벼운 기능 UI를 유지한다. 향후 재설계 범위가 정해지기 전 화면을 임의로 전면 교체하거나 최종 디자인 인수 완료로 처리하지 않는다. 제품 계약을 바꾸는 선택은 해당 주제 문서와 상태표에 함께 남긴다.
