# 개발 순서와 인수 기준

2026-09-15에 공식 위젯 22개와 선택 설치 관리의 소스를 구현했다. 이 문서는 완료한 구현과 남은 실제 환경 검증·외부 확장을 나눈다. 최종 실행 근거는 [위젯 검증 기록](../VALIDATION-WIDGETS.md), 제품 범위는 [상태표](../status.md)를 따른다. 소스 완료와 릴리스 배포 완료는 별개다.

## 구현한 공식 도구 단계

| 단계 | 현재 소스 범위 |
| --- | --- |
| 0 · 선택 설치 | 동봉 manifest 선택·검사·설치·끄기·제거·재설치, 데이터 보존, 주사위·동전·가위바위보 |
| 1 · 로컬 할 일 | 목록·CRUD·오늘·루틴·장보기·완료·취소·일/주/월 반복·명시적 선택 이월 |
| 2 · 읽기 캘린더 | Google Desktop OAuth, ICS/webcal, 시간대·종일·반복 예외, 오늘·다음 일정·빈 시간과 opt-in 알림 |
| 3 · 집중과 결과 | 집중·휴식·계속·취소, 명시적 완료, 완료 구슬병·화분 |
| 4 · 생활 도구 | 준비 봉투·시계/기념일·메모·명시 지역 날씨·macOS 현재 음악·기기 상태 |
| 5 · 놀이와 기록 | 캐릭터 교감·공·비행기·방울·맞히기·낚시·운세·펫·획득품·소품·사건 일지 |

22개 설치 단위는 [카탈로그](../widgets/catalog.md)에서 관리한다. 캐릭터팩 편집·교체·JSON 공유는 기존 0.3.0 기능이며 위젯 패키지 수에 포함하지 않는다. 통합 오늘 브리핑은 별도 후속 보기 제안이다.

공식 설치는 목록에 동봉한 manifest를 사용자 설치 공간에 등록하는 방식이다. 실행 코드와 화면은 앱에 포함되므로 외부 SDK나 동적 코드 실행 플랫폼을 완성했다는 뜻이 아니다. 설치 용량 표시의 의미는 [설치 범위](../widgets/installation.md#첫-구현의-패키지-범위)를 따른다.

## 다음 검증

1. 최신 소스로 전체 테스트·정적 검사·빌드를 실행하고 기록한다.
2. 격리된 macOS 사용자 데이터에서 첫 선택/건너뛰기, 22개 화면·조작, 데이터 보존·재시작·끄기·제거와 실제 말풍선 중단을 관찰한다.
3. 별도 사용자 동의를 받아 Google 실제 계정 OAuth·갱신·해제를 확인한다. 계정이나 비밀 구독 주소를 fixture에 저장하지 않는다.
4. Windows 설치·실행과 OS별 음악·배터리·복귀 차이를 검증한다.
5. 같은 환경에서 위젯 없음/실행/화면 닫힘의 CPU·메모리 등 자원 사용을 측정한다. 과거 빌드 수치를 가져오지 않는다.

## 외부 Widget SDK와 패키지 설치 (후속)

공식 도구로 검증한 상태·사건·명령·권한 계약을 공개하고 개발용 폴더·외부 ZIP·호환 버전·이벤트 시험 도구를 제공한다. 아직 공개 CLI나 설치 가능한 외부 규격은 없다.

인수 조건:

- 외부 패키지를 앱 재빌드 없이 설치하고 자신의 상태·사건·동작을 연결한다.
- 다른 위젯·공통 DB·자격 증명·허용되지 않은 파일과 네트워크 접근을 거부한다.
- 비활성화·연결 해제 이후 결과가 재적용되지 않고, 외부 본문이 실행 지침으로 승격되지 않는다.
- 예제와 오류·중복·재시도·최신성 검증 절차를 함께 공개한다.

## 커스텀 화면·원격 배포 (후속)

필요성이 확인된 경우에만 커스텀 HTML/CSS/JavaScript 화면과 실행 범위를 정한다. 별도 WebView 자체를 완전한 샌드박스로 표현하지 않는다. 원격 저장소·서명·마켓·자동 업데이트와 임의 native/WASM 실행은 별도 설계·검증 대상이다.

Cargo workspace는 별도 Rust 패키지 사이에 실제 공통 계약이 생길 때 도입한다. Windows·다중 모니터·장시간 자원 사용·모델 의미 품질은 각 기능의 단위 테스트와 별도로 확인한다.
