# Nanika Box 제품 사양

이 문서는 기존 **0.2 기준**을 보존한다. 전체 프로젝트의 최신 사양 입구는 [Comet 사양 안내](index.md)이며, 이후 확정한 투두·캘린더·외부 위젯은 [구현 상태](status.md)와 연결된 주제별 문서에서 다룬다. 아래 인수 결과는 0.2 검증 기록이며 확장 기능의 구현 완료를 의미하지 않는다.

이 문서는 **0.2 제품 방향과 인수 기준을 확정한 계약**이다. 화면, 대화 흐름, 자동 잡담 또는 추론 방식을 변경할 때 이 문서를 기준으로 판단한다. 각 항목은 구현해야 할 동작을 정의하며, 특정 빌드의 구현·실측 완료를 선언하지 않는다. 실행 방법은 저장소 루트의 `README.md`를 참고한다.

## 제품의 중심

Nanika Box는 나니카·우카가카처럼 바탕화면에 머물며 서로 이야기하는 A와 B다. 사용자가 질문하지 않아도 인사하고, 짧게 수다를 떨고, 다시 조용해진다. LLM은 새로운 대화를 더하는 선택 기능이다. 모델 다운로드나 API 설정을 하지 않은 첫 실행에도 이 기본 경험이 성립해야 한다.

주 화면은 작은 캐릭터 본체와 잠시 나타나는 말풍선이다. 대화 기록·친밀도·설정·단어장 편집은 필요할 때 여는 보조 화면에 둔다. 큰 채팅 패널 두 개를 상시 표시하는 0.1 화면 구성을 제품의 기본 화면으로 사용하지 않는다. 이번 범위에는 본격적인 캐릭터 일러스트, 투명 아트, 음성 입출력, 웹 검색, 화면 감시를 포함하지 않는다.

## 본체와 말풍선

| 요소 | 확정 동작 |
| --- | --- |
| A/B 본체 | 각각 112×88 크기의 작은 불투명 창으로 상주한다. 간단한 이름·표정 표시를 임시 캐릭터 표현으로 사용한다. |
| 말풍선 | 폭 320의 공용 말풍선 하나를 현재 말하는 캐릭터 옆에 표시한다. 여러 말풍선을 동시에 남겨 두지 않는다. |
| 장면 | 기본 대사와 LLM 자동 장면은 2~4줄이며 A→B→A처럼 화자를 번갈아 표시한다. |
| 표시 시간 | 각 대사의 글자 수에 따라 읽을 시간을 확보한다. 장면이 끝나면 말풍선을 닫고 본체만 남긴다. 이전 대사는 다음 장면까지 화면에 고정하지 않는다. |
| 본체 조작 | 클릭 또는 우클릭으로 메뉴를 열고, 더블클릭으로 입력을 연다. 본체를 끌어 위치를 옮긴다. |
| 보조 화면 | 직접 입력, 대화 기록, 친밀도, 설정, 단어장을 필요할 때 연다. 입력의 한국어 조합 Enter는 전송으로 처리하지 않는다. |

단어장 대사는 사용자가 작성한 결과물이다. 단어장의 1~8줄 구성과 화자 순서는 그대로 재생하며, 일반 자동 장면의 교대 규칙에 맞추려고 재작성하지 않는다.

## 사용자가 말하지 않아도 이어지는 잡담

1. 실행 약 5초 후 내장 인사 장면을 재생한다. 사용자 입력, 로컬 모델, API 연결이 필요하지 않다.
2. 이후 잡담 간격의 기본값은 2분이다. 반복이 기계적으로 느껴지지 않도록 각 간격에 ±20% 변동을 적용한다.
3. 자동 장면의 재료는 내장 대사, 사용자가 자동 잡담에 허용한 단어장 항목, 준비된 LLM 장면이다. 모델이 없거나 준비 대사가 없어도 내장 대사가 기본 경험을 이어 간다.
4. 사용자 입력이 들어오면 진행 중인 자동 장면과 오래된 생성 작업을 취소하고 사용자 입력을 우선한다. 취소된 장면의 남은 대사는 뒤늦게 재생하지 않는다.
5. 재시작할 때 이전 실행의 말풍선·재생 커서·준비 장면을 이어 재생하지 않는다. 대화 기록과 설정은 보존하되 새로운 실행의 인사 흐름으로 시작한다.

### 자동 동작 설정

| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| `autonomousEnabled` | `true` | 자동 생성과 자동 재생 전체의 상위 스위치. 끄면 내장·단어장·준비 장면의 자동 재생도 멈춘다. |
| `localIdleEnabled` | `true` | 로컬 LLM으로 새 자동 장면을 준비할 수 있는지 결정한다. 내장 대사 재생의 필수 조건이 아니다. |
| `apiIdleEnabled` | `false` | 외부 API를 이용한 자동 장면 준비를 허용한다. 기본 상태에서 자동 장면 생성 비용을 발생시키지 않는다. |
| `idleMinutes` | `2` | 정기 잡담의 기준 간격. |
| 실행 중 일시정지·숨김 | 실행 상태 | 자동 생성과 자동 재생을 모두 멈춘다. 자동 잡담 일시정지는 사용자가 직접 요청한 답변을 취소하지 않는다. |

자동 동작이 꺼져 있어도 사용자가 직접 입력한 단어장 키워드는 처리한다. `apiIdleEnabled=false`는 모든 API 요청을 금지한다는 뜻이 아니다. 사용자가 요청한 API 대화·연결 확인·그 대화의 기억 분석은 별도 요청을 발생시킬 수 있다.

## 단어장: 등록한 대사를 그대로 재생

사용자 입력의 단어장 매칭은 **LLM 호출과 모델 준비 상태 검사보다 먼저** 수행한다. 일치 항목이 있으면 해당 항목의 대사를 사용하며, LLM으로 내용을 바꾸거나 덧붙이지 않는다. 따라서 모델이 없는 상태와 API 키가 없는 상태에서도 키워드 대화는 동작한다.

매칭 규칙은 다음과 같다.

- 활성화된 항목의 키워드가 입력에 문자 그대로 포함되는지 비교한다. 대소문자는 구분하지 않는다.
- 여러 키워드가 일치하면 가장 긴 키워드를 우선한다.
- 길이가 같으면 먼저 등록한 항목을 사용한다. 항목 내용을 수정해도 최초 등록 순서는 바뀌지 않는다.
- 정규식·의미 검색·LLM의 유사 표현 추측으로 범위를 확장하지 않는다.

### 항목 구조와 편집

| 항목 | 규칙 |
| --- | --- |
| 제목 | 사람이 목록에서 구분할 이름. |
| 키워드 | 1~20개. 화면에서는 쉼표나 줄바꿈으로 입력한다. |
| 대사 | 1~8줄. 각 줄에 화자 A/B, 표정, 본문을 지정한다. 추가·삭제·순서 변경을 지원한다. |
| 표정 | 평온, 기쁨, 호기심, 생각중, 걱정, 장난. |
| `enabled` | 해당 항목의 사용 여부. |
| `useForIdle` | 자동 잡담 재료로도 허용할지 선택한다. 새 항목의 기본값은 `false`다. |

등록한 본문의 공백·줄바꿈과 화자·대사 순서를 보존한다. 관계 점수나 캐릭터 프롬프트를 이유로 원문을 고치지 않는다. 다른 상태 이벤트가 도착해도 수정 중인 초안을 덮어쓰지 않으며 저장 실패 시 입력을 유지한다.

항목은 SQLite에 저장한다. 초기 예제 두 개는 초기화 표시와 함께 한 번만 등록하며, 사용자가 수정·삭제한 예제를 재시작이나 빈 목록을 이유로 복원하지 않는다.

## 선택적인 LLM과 자원 사용

로컬 기본 모델은 Qwen3.5-4B이며 Qwen3.5-9B를 선택할 수 있다. 모델별 다운로드·검증·이어받기 상태를 구분하고 한 번에 선택 모델의 추론 프로세스 하나만 실행한다. 모델 선택은 기록·기억·친밀도·단어장을 초기화하지 않는다. 기존 4B 설정은 그대로 읽을 수 있어야 한다.

직접 입력이 단어장과 일치하지 않을 때 선택한 로컬 모델 또는 API로 응답한다. 모델이 필요한 요청에서 준비가 부족하면 설정 방법을 안내하되, 기본 자동 잡담이나 등록 대사의 실행을 막지 않는다.

LLM 자동 장면은 최대 3개만 준비한다. 선택 모델·기억·설정 변경과 새 사용자 입력으로 무효화된 결과를 재생하지 않는다. 준비 실패는 짧은 반복 루프로 재시도하지 않으며, 재시도 간격은 최소 60초이면서 설정된 잡담 간격보다 짧지 않아야 한다. 외부 API 자동 장면 생성의 시간당 2회 제한은 재시작 후에도 유지한다.

자동 잡담을 위해 LLM을 항상 실행하거나, 준비 작업으로 모델의 상주 시간을 계속 연장하지 않는다. 내장 대사와 등록 대사만으로도 조용한 상주 상태를 유지할 수 있어야 한다. 자원 검증은 본체만 표시되는 상태, 대사 재생, 모델 준비·추론·해제 상태를 구분해 수행한다.

현재 `src-tauri/src/resources.rs`는 Unix에서 로컬 LLM 장면 준비 시점에만 1분 load average를 논리 CPU 수로 나눈 값이 `0.65` 미만인지 확인한다. 이는 준비를 미루기 위한 거친 부하 지표이며 실제 CPU 사용률 65%를 뜻하지 않는다. 값을 얻지 못하거나 유한하지 않은 값·음수·유효하지 않은 CPU 수이면 준비를 허용하지 않는다. 별도의 상시 부하 감시 작업은 만들지 않는다. Windows에는 현재 이 추가 부하 검사를 적용하지 않으며, 공통 준비 간격·시간 제한에 의존한다.

`src-tauri/src/lib.rs`는 각 백그라운드 추론을 최대 45초로 제한한다. 자동 잡담이 켜져 있으면 다음 재생 예정 시각까지 남은 시간과 45초 중 짧은 시간을 사용하되 최소 1초를 부여한다. 제한 시간이 지나면 작업을 중단하고, 로컬 추론 프로세스도 종료한다. 새 장면 생성이나 기억 분석이 내장 잡담의 예정 재생을 장시간 가로막지 않도록 하는 경계이며, 정확한 시각의 재생이나 특정 성능 수치를 보장하는 것은 아니다.

## 기록·기억·친밀도의 경계

대화 기록은 보조 화면에서 확인한다. 준비했지만 실제 재생하지 않은 대사를 이미 나눈 대화로 저장하지 않는다. 내장·단어장·LLM의 캐릭터 대사는 사용자 사실의 근거로 사용하지 않는다.

장기 기억은 사용자 원문과 근거를 연결한다. 정정·수동 수정·삭제를 우선하고, 폐기된 출처가 다음 모델 문맥에서 기존 사실로 되살아나지 않게 한다. 전체 원문 기록은 보존한다. 모델 출력의 JSON 형식이 올바르더라도 사실성이 보장되는 것은 아니다.

친밀도는 A→사용자와 B→사용자를 별도로 관리하며, 말투에만 제한적으로 반영한다. 모델이 점수를 직접 결정하지 않는다. 불확실한 의미 판정, 사용자의 정정·반대·자리 비움으로 점수를 낮추지 않는다. 기능이나 답변 정확성을 친밀도로 제한하지 않는다.

다음은 0.2.0의 인수 기준과 확인 범위다. 체크된 항목은 괄호 안의 검증 방식으로 확인했으며, 모두를 네이티브에서 반복 검증했다는 뜻은 아니다. 관찰 결과와 제한은 [0.2.0 검증 기록](VALIDATION-0.2.0.md)을 참고한다.

- [x] 모델·API 설정·사용자 입력 없이 실행 후 인사가 나오고, 정기 잡담도 이어진다. (네이티브: 모델·API 없는 실행과 다음 정기 장면)
