# 0.2.0 검증 기록

2026-09-15, macOS Apple Silicon에서 수행한 최종 패키지 검증 기록이다. [제품 사양](PRODUCT.md)의 인수 기준과 연결하며, Windows나 장시간 자원 사용 검증을 대신하지 않는다.

## 코드와 패키지

- Rust 라이브러리 테스트 43개, 프론트엔드 테스트 16개 통과.
- Rust 전체 target 테스트 통과. 예제에 포함된 공유 모듈 테스트는 중복이므로 테스트 개수에 더하지 않았다.
- `cargo clippy --lib --bins -- -D warnings` 통과. 전체 target Clippy에는 기존 예제의 미사용 코드·clone 관련 경고가 남아 있다.
- 최종 0.2.0 macOS 패키지 빌드 완료. `codesign --verify --deep --strict`와 `hdiutil verify` 통과. 이 검사는 notarization을 뜻하지 않는다.

## 실제 데스크톱 동작

| 확인 항목 | 관찰 결과 |
| --- | --- |
| 모델 없는 자동 인사 | 기존 모델 폴더를 임시로 치우고 API 미설정 상태에서 약 19:15:59 KST에 실행했다. 19:16:05경 첫 대사가 표시되어 약 5~6초 후 인사를 시작했다. A→B→A→B 네 줄을 재생했다. |
| 입력 없는 정기 잡담 | 첫 자동 장면 시작 약 138초 후 A→B→A 장면을 재생했다. 그 사이 사용자 입력은 없었다. 기본 2분 ±20% 범위의 한 차례 관찰이다. |
| 본체와 말풍선 | 현재 화자의 말풍선이 잠시 나타났다가 사라지고 112×88 본체만 남는 것을 확인했다. |
| 모델 없는 키워드 | `안녕` 입력에 A의 `안녕! 잠깐 이야기할까?`, B의 `반가워. 편하게 말 걸어 줘.`를 순서대로 재생했다. llama 프로세스는 없었다. |
| 단어장 저장·재시작·삭제 | GUI에서 앞뒤 공백과 빈 줄을 포함한 QA 항목을 만들고 자동 잡담 허용을 켰다. 종료·재실행 후 원문과 설정이 그대로 저장되어 있음을 확인했다. GUI로 QA 항목을 삭제했으며 초기 예제 두 개만 남겼다. |
| 로컬 모델 대화 | 기존 4B/9B 캐시를 복원한 뒤 GUI의 4B 준비 상태를 확인했다. 단어장에 없는 B 대상 요청의 4B 응답이 성공하고 말풍선이 사라졌다. |
| 종료 시 프로세스 정리 | 앱 소유 llama-server가 실행 중인 상태에서 종료했다. 앱과 해당 서버 프로세스가 모두 사라졌다. |
| 기존 기록 보존 | 작업 전 기존 메시지 9개의 JSON을 작업 후 값과 비교하여 정확히 일치함을 확인했다. |

## 단위·컴포넌트 검증이 보완하는 범위

`src-tauri/src/lib.rs`는 모델 없는 키워드 경로, 오래된 재생·타이머 거부, 자동 동작의 일시정지·숨김·입력·상위 스위치 경계, 재시작 시 준비 장면 폐기, 모델 변경과 다운로드 상태, API 자동 요청 한도, 종료 정리를 검사한다. `src-tauri/src/wordbook.rs`는 긴 키워드·등록 순서·비활성 항목, 정확한 원문과 순서, CRUD와 삭제한 예제의 비복원을 검사한다.

`src-tauri/src/domain.rs`는 LLM 장면의 연속 동일 화자를 거부하고 B→A→B를 허용한다. `src-tauri/src/store.rs`는 기억 근거·정정·삭제와 친밀도 상한을 검사한다. `src/__tests__/`는 원문 공백 표시, 말풍선과 입력 우선순위, 한국어 조합 입력, 수정 초안·오류 시 입력 유지, 모델별 상태를 검사한다.

## 남은 검증과 해석 한계

- Windows 네이티브 실행·설치와 다중 모니터 배치는 확인하지 않았다.
- 장시간 자동 잡담 중 CPU·메모리 사용량, 모델 해제 주기·재로딩 비용은 측정하지 않았다. 부하 지표·재시도·시간 제한의 코드 검증은 실제 자원 사용 벤치마크가 아니다.
- 네이티브 4B 요청 한 번의 성공은 모델 전반의 사실성이나 9B와의 품질 비교 결과가 아니다.
- 입력 취소·일시정지·숨김·상위 스위치의 모든 조합을 GUI로 반복 검증한 기록은 아니다. 해당 경계는 위 단위·컴포넌트 검증과 구분한다.
