# 할 일·일정·대화의 조작 구분

기존 작은 본체와 말풍선, 다이어리 화면을 유지하면서 조작의 의미와 현재 범위를 명확하게 한다. 이 문서는 기존 [다이어리](planning.md)와 [대화](conversation.md) 계약의 보완이며, 과거 검증 결과를 새 구현의 실행 결과로 사용하지 않는다.

## 할 일과 메모

- 체크박스는 완료 상태를 바꾸고, 제목은 선택·읽기 전용 상세를 연다. 집중 시작과 편집은 별도 동작이다. 타이머 종료가 할 일을 자동 완료하지 않는다.
- 완료 후에는 되돌리기를 제공한다. 반복 할 일은 기존 원본·발생 항목·주간 기록의 취소 규칙을 따른다.
- 접힌 목록에서도 마감 날짜와 시각을 표시한다. 계획 날짜와 마감 날짜를 별도로 보존한다. 오늘·내일 같은 보조 표현은 기기의 현재 날짜를 기준으로 하고 절대 날짜를 대신하지 않는다.
- 다이어리의 선택 날짜를 할 일 관리에서도 사용한다. 날짜 탐색은 원본 할 일의 계획 날짜·마감·완료 상태를 변경하지 않는다. 빈 상태는 현재 조회 범위를 명시한다.
- 작업 메모는 읽기 전용 상세나 첫 줄에서 확인한다. 고정 메모는 모든 날짜에 적용되는 메모임을 알리고, 일정의 안건과 구분한다.
- 작성 모드, 입력 예시와 추가 동작을 명시한다. 메모의 Enter는 줄바꿈이며, 다른 모드의 제출 동작과 구분한다.

## 일정

- 제목 전체와 안건은 편집을 시작하지 않고 읽을 수 있다. 편집은 명시적으로 선택한다.
- 날짜·시각 입력에는 현재 기기의 시간대 이름을 표시한다. 저장 형식과 시간대 변환 규칙은 바꾸지 않는다.
- 사용자가 길이 유지 옵션을 선택하면 시작 변경에 맞춰 종료도 이동한다. 기본 개별 입력과 종일 일정의 포함 종료 날짜 규칙을 유지한다.
- 현재 읽은 일정과의 겹침은 안내만 제공하며 저장을 막지 않는다. 아직 조회하지 않은 일정까지 충돌이 없다고 보장하지 않는다.
- 잘못된 날짜·시간을 고치면 이전 입력 검증 오류를 지운다. 저장 실패와 충돌은 별도 오류로 유지하고 초안을 보존한다.

## 대화와 단어장

- 입력 전에 등록 대사·혼잣말과 선택적 AI 대화의 준비 상태를 구분한다. 모델이 없어도 등록 키워드 매칭은 가능하다.
- 실제 기록의 출처에 따라 등록 대사·자동 대사·AI 응답을 구분한다. 확인할 수 없는 출처를 AI나 단어장으로 추정하지 않는다.
- 실패한 이번 입력은 답변을 받지 못했거나 답변이 끝나지 않았음을 알리고 직전 답변과 구분한다. 현재 입력의 일부 답변이 이미 표시됐다면 그 원문을 보존한다. 실패 입력은 보존하며 모델을 자동 다운로드하지 않는다.
- 단어장의 작업·휴식·일상 그룹은 선택적 정리 정보다. 필터나 그룹이 실제 키워드 재생 조건을 바꾸지 않는다.
- 입력 시험은 저장된 활성 항목에 실제 매칭 규칙을 적용한 결과를 보여준다. 긴 키워드 우선, 길이가 같으면 먼저 등록한 항목을 선택하는 기존 규칙을 유지한다.
- 중복 키워드는 알리되 자동 삭제하거나 기존 대사를 덮어쓰지 않는다. 본문·공백·줄바꿈·화자 순서와 기존 미리보기 재생을 유지한다.

## 검증 경계

자동화된 UI·저장·매칭 회귀 테스트와 플랫폼별 컴파일·테스트, 패키지의 실제 데스크톱 조작을 구분해서 확인한다. OS 알림 전달, 외부 캘린더 실계정, 생성형 모델의 답변 품질은 해당 환경에서 별도 관찰해야 한다.
