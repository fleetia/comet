# 바탕화면 상주 경험

기준일: 2026-09-15. Comet은 나니카·우카가카처럼 바탕화면에 머무는 A/B와 선택적인 LLM을 결합한다. 이 문서는 창과 상호작용을 변경할 때 기본 경험을 판단하는 기준이다.

| 상태 | 범위 |
| --- | --- |
| 구현됨 · 0.2 | 0.2의 작은 A/B 본체, 공용 말풍선, 내장 자동 수다, 직접 입력, 단어장과 보조 화면 |
| 확정 · 개발 예정 | 같은 상주 경험 안에서 장난감과 할 일·일정을 꺼내 쓰고 캐릭터가 상태를 언급한다. |
| 미정 | 캐릭터 아트, 장난감별 배치 세부, 조용한 시간의 정확한 시간대·설정 방식 |

0.2의 기준과 당시 확인 범위는 [기존 제품 사양](../PRODUCT.md), [검증 기록](../VALIDATION-0.2.0.md)에 있다. 이 문서의 계획은 해당 빌드에서 구현됐다는 뜻이 아니다.

## 기본 화면

항상 보이는 기본 요소는 작은 A/B 본체다. 배경판이 있는 대시보드나 큰 채팅 패널을 기본 화면으로 만들지 않는다. 필요한 대화·도구를 잠깐 표시하고 다시 바탕화면으로 돌아온다.

| 요소 | 동작 |
| --- | --- |
| 본체 | 현재 각각 112×88의 불투명 창에 이름과 텍스트 표정을 표시한다. 이 임시 표현을 허용하며, 아트 완성을 기능의 선행 조건으로 삼지 않는다. |
| 말풍선 | 폭 320의 공용 말풍선 하나가 현재 화자 곁에 나타난다. 대사 길이에 따른 표시 시간이 지나면 다음 줄로 넘어간다. |
| 장면 종료 | 말풍선이 사라지고 본체만 남는다. 마지막 대사를 계속 고정하지 않는다. |
| 메뉴·입력 | 본체 클릭·우클릭으로 메뉴, 더블클릭으로 입력을 연다. 한국어 조합 확정 Enter로 전송하지 않는다. |
| 이동 | 본체를 끌어 위치를 옮긴다. |
| 보조 화면 | 기록·친밀도·설정·단어장과 향후 할 일·일정 상세는 요청했을 때 연다. |
| 장난감 | 향후 사용자가 꺼낸 장난감만 표시하며 정리하면 사라진다. 기본 바탕화면을 도구 목록으로 채우지 않는다. |

## 자동 수다와 침묵

모델·API·사용자 입력 없이 실행 약 5초 후 내장 인사를 시작한다. 이후 기본 2분 간격에 ±20% 변동을 둔다. 기본·LLM 자동 장면은 2~4줄이며 A/B가 번갈아 말한다. 단어장은 작성한 화자 순서를 보존하는 별도 규칙을 따른다.

| 설정 | 기본값과 범위 |
| --- | --- |
| `autonomousEnabled` | 켜짐. 자동 생성과 내장·단어장·LLM 장면의 자동 재생 전체를 제어한다. |
| `localIdleEnabled` | 켜짐. 로컬 LLM의 새 장면 준비를 제어한다. 내장 수다는 모델 없이도 동작한다. |
| `apiIdleEnabled` | 꺼짐. API로 자동 장면을 만드는 비용은 사용자가 허용한 경우에만 발생한다. |
| 일시정지·숨김 | 자동 생성과 재생을 함께 멈춘다. 자동 수다 일시정지가 직접 요청한 답변을 취소하지 않는다. |

사용자 입력은 자동 장면보다 우선한다. 중단된 장면의 남은 줄이나 오래된 생성 결과가 뒤늦게 끼어들지 않는다. 재시작은 새 인사 흐름이며 이전 실행의 재생 위치·준비 장면을 이어 쓰지 않는다. 기록과 설정은 보존한다.

## 확장에서도 유지할 경계

캐릭터의 개별 교체와 공유도 확정된 확장 요구다. 처음에는 두 자리와 텍스트 표정 상자를 유지하며, 한 명 또는 둘의 조합을 바꾸는 설계는 [캐릭터 교체와 공유](characters.md)를 따른다. 교체가 이전 캐릭터의 기록을 새 화자의 기록으로 바꾸지 않아야 한다.

장난감 반응과 일정 알림이 들어와도 공용 말풍선에 무제한 쌓지 않는다. 사용자가 직접 요청한 동작을 우선하고, 지난 사건을 늦게 연달아 읽어 주지 않는다. 발화 순서는 사용자와 진행 중인 대화 → 시각이 중요한 알림 → 위젯 사건 반응 → 평소 수다로 정한다. 같은 사건의 합치기와 만료 기준 등 구체 수치는 확장 구현 전에 정한다. 상세는 [위젯 수명과 실행 규칙](../widgets/lifecycle.md)을 따른다.

조용한 시간과 알림 빈도 조절은 계획에 포함하지만 정확한 시간대와 기본값은 미정이다. 그 설정을 정하기 전부터 밤 시간이나 회의 참석 여부를 추측해 확정 상태처럼 취급하지 않는다. 할 일을 놓치거나 앱을 오래 켜지 않은 것으로 친밀도를 낮추지 않는다.

가벼운 상주는 Rust 사용만으로 보장되지 않는다. 내장 대사와 도구 사용에 LLM 상시 실행을 요구하지 않으며, 화면이 조용할 때 장난감 애니메이션·폴링이 계속 필요할지 개별 검토한다. 현재 LLM 자원 제한과 미측정 범위는 [기존 제품 사양](../PRODUCT.md)을 따른다.

## 인수 조건

- 모델 없는 첫 실행에서 인사와 다음 정기 수다가 나온다.
- 장면이 끝나면 본체만 남으며, 화자 이동에 따라 공용 말풍선이 따라간다.
- 사용자 입력·일시정지·숨김·자동 설정 해제 후 오래된 자동 대사가 재생되지 않는다.
- 보조 화면과 장난감을 닫으면 별도의 대시보드가 남지 않는다.
- 새 기능이 기존 창 위치·기록·설정을 초기화하지 않는다.
- 장시간 자원 사용, Windows와 다중 모니터 검증은 실제 수행한 결과만 별도로 기록한다.

창 구조·기본 주기·입력 우선순위가 바뀌면 이 문서를 갱신한다. 대화 규칙은 [대화와 기억](conversation.md), 도구의 범위는 [장난감](toys.md)과 [할 일·일정](planning.md)을 참고한다.
