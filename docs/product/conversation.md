# 대화와 기억

기준일: 2026-09-19. 대사의 출처, 회상 수명과 실제 상태를 구분하는 제품 규칙이다. LLM이 만든 내용을 캐릭터의 확정 설정이나 사용자 사실로 승격하지 않는다. 이 규칙이 생성 대사의 사실성까지 보장하지는 않는다.

| 상태 | 범위 |
| --- | --- |
| 구현됨 · 0.2 | 내장 수다·키워드 단어장·선택적인 로컬/API 대화, 원문 근거 기억, A/B별 친밀도 |
| 구현됨 · 0.3.0용 소스 | 로컬 캐릭터 편집·교체·공유, 캐릭터 소유 대사와 로컬 ID별 관계·과거 이름 보존. 네이티브 검증 진행 중 |

0.2의 기존 기준과 관찰은 [제품 사양](../PRODUCT.md)과 [검증 기록](../VALIDATION-0.2.0.md)에 둔다. 캐릭터 기능 소스의 현재 계약은 [캐릭터 사양](characters.md)을 따르며 최종 검증은 진행 중이다. 공식 위젯의 사건 연동과 외부 SDK의 후속 계약은 구분하며 현재 검증은 [위젯 검증 기록](../VALIDATION-WIDGETS.md)을 따른다.

## 대사의 선택 순서

1. 사용자 입력에서 활성 단어장 키워드를 찾는다. 모델 준비 검사보다 먼저 수행한다.
2. 일치하면 등록 대사를 그대로 재생한다. 모델이나 API 키가 필요하지 않다.
3. 개인 항목이 없으면 현재 캐릭터·조합의 활성 단어장을 같은 원문 보존 규칙으로 찾는다. 캐릭터팩과 편집 범위는 [캐릭터 교체와 공유](characters.md)를 따른다.
4. 일치하지 않는 직접 대화는 선택한 로컬 모델 또는 API로 요청한다. 준비가 부족하면 설정 방법을 안내한다.
5. 자동 수다는 내장 대사로도 유지한다. 첫 인사 뒤 위젯 상태 `.talk` 차례와 기존 일반 수다 차례를 번갈아 사용한다. 위젯 상태 후보가 없으면 기존 일반 경로로 진행한다. 실제 사건 대본은 별도 사건 대기열을 따른다. LLM 준비가 실패했다고 기본 경험까지 멈추지 않는다.

내장 기본 A는 호기심이 많고 다정하며 먼저 말을 건다. 내장 기본 B는 차분하고 간결하며 부드러운 농담을 한다. 교체한 캐릭터는 저장한 성격과 말투를 사용한다. 기본 A/B 대사는 기존 순서를 유지한다. 2명 이상 LLM 자동 장면은 2~4줄이며 같은 화자의 연속 발화를 허용한다. 1명 LLM 자동 장면은 독백 또는 사용자에게 묻는 한 줄이다. JSON 형식이나 화자 검증을 통과해도 대사 내용의 사실성까지 보장되지는 않는다.

캐릭터 편집·공유 형식, 로컬 관계 식별과 소유 대사의 상세는 [캐릭터 사양](characters.md)을 따른다. 개인 단어장의 기존 매칭·원문 재생 규칙은 유지한다.

## 선택한 친구와 모두에게 말하기

직접 입력의 `target`은 로컬 캐릭터 ID 또는 `all`이다. 요청 시점의 활성 목록과 순서를 별도로 저장한다. 2명에게 보내면 한 번 생성해 정확히 요청 순서의 두 대사를 검증하고 재생한다. 3~8명은 요청 순서대로 한 명씩 생성·표시한다. 각 캐릭터는 한 개의 대사 객체로 답하며, 이전 친구가 실제로 표시한 같은 turn의 답은 허용된 회상 문맥 안에서만 참고한다. 말풍선은 하나를 공유하고 현재 화자 옆으로 이동한다.

각 캐릭터의 이름·설정·친밀도·허용된 과거 경험을 구분한다. 삭제·수정된 기억의 출처, 교체된 친구의 경험, 만료된 생성 대사를 원문 기록에서 다시 가져오지 않는다. 두 명 응답은 전체 형식을 검증하기 전에는 어느 대사도 표시하거나 저장하지 않는다. API 제공자가 구조화된 응답 옵션을 거부할 때의 기존 호환 재요청은 별도다.

대사를 실제로 표시할 때만 완료로 기록한다. 중단·설정 변경·캐릭터 교체 후 남은 대사는 폐기한다. 재시도는 요청 당시 대상·순서를 사용하고 이미 완료한 화자는 제외한다. `all` 재시도에 새로 들어온 캐릭터를 추가하지 않는다. 원래 대상이 나갔다면 새 메시지로 요청해야 한다.

### 1명일 때의 자동 대화

한 명의 LLM 자동 장면은 독백 또는 짧은 질문이다. 질문을 읽을 시간이 지난 뒤 약 30초 동안 답을 기다린다. 입력 화면을 열면 기존 작업 취소 경계에서 기다림을 해제하고 초안을 받을 수 있다. 입력·숨김·일시정지·자동 동작 끄기·캐릭터 교체는 이전 질문 타이머를 무효화한다. 답이 없으면 질문을 닫고 다음 자동 수다까지 기다린다. 모델이 준비되지 않아도 캐릭터에 등록된 인사·개별 수다는 동작한다.

## 단어장 계약

| 항목 | 규칙 |
| --- | --- |
| 매칭 | 대소문자를 구분하지 않는 문자 그대로의 포함 검색. 의미 유사도·정규식으로 확장하지 않는다. |
| 우선순위 | 가장 긴 일치 키워드 우선. 동률이면 먼저 등록한 항목. 수정해도 등록 순서는 바뀌지 않는다. |
| 편집 | 제목, 키워드 1~20개, 대사 1~8줄, 각 화자·표정·본문, 활성화 여부 |
| 화자 | 개인 단어장은 현재 자리 A~H. 기존 A/B 항목을 특정 캐릭터에 고정하지 않는다. 없는 자리를 요구하는 장면은 전체 후보에서 제외한다. |
| 표정 | 평온, 기쁨, 호기심, 생각중, 걱정, 장난 |
| 자동 사용 | 항목별 `useForIdle` 선택. 새 항목은 기본 꺼짐. |
| 원문 보존 | 앞뒤 공백·빈 줄·문구·화자 순서를 보존한다. LLM과 친밀도가 등록 대사를 재작성하지 않는다. |
| 저장 | SQLite에 보관. 초기 예제 두 개는 한 번만 등록하며 삭제한 예제를 복원하지 않는다. |

단어장에는 A→A→B처럼 사용자가 정한 순서도 허용한다. 작성한 화자 순서를 바꾸거나 없는 화자를 다른 친구로 대체하지 않는다. 저장 실패나 다른 상태 갱신이 편집 중 초안을 지우지 않는다.

## 모델은 선택 기능

기본 로컬 모델은 Qwen3.5-4B이며 고정 목록의 비교용 모델이나 직접 지정한 GGUF 파일을 선택할 수 있다. 한 번에 선택 모델의 프로세스 하나만 실행한다. **llama.cpp는 추론 실행기이며 Llama 계열 모델을 선택했다는 뜻이 아니다.** 모델 선택·다운로드 상태 변경이 기록·기억·친밀도·단어장을 초기화하지 않는다.

API 모드는 필요한 대화와 기억을 선택한 제공자에게 전송한다. API 자동 생성은 기본 꺼짐이며, 직접 대화·연결 확인·그 대화의 기억 분석은 별도 요청을 발생시킬 수 있다. 모델 파일·실행 설정·자원 제한의 상세는 [기존 제품 사양](../PRODUCT.md)에 둔다.

## 근거의 종류

| 근거 | 허용하는 표현 | 금지하는 확대 |
| --- | --- | --- |
| 사용자 원문과 활성 기억 | 사용자가 말한 취향·정정 인용 | 캐릭터가 만든 사실을 사용자 기억으로 저장 |
| 장난감 상태 | 실제 주사위 눈·승패·획득한 물건 언급 | 굴리지 않은 결과나 없는 수집품 언급 |
| 내장 할 일 | 실제 목록·기한·완료 상태 언급 | 타이머 종료를 할 일 완료로 선언 |
| 캘린더 조회 결과 | 연결한 일정의 제목·시각과 갱신 상태 안내 | 캘린더 공백을 사용자의 확실한 자유 시간으로 단정 |
| 가상 캐릭터 표현 | “내가 이길 줄 알았는데!” 같은 감정 연기 | 그 연기를 실제 사용자 행동의 증거로 취급 |

출처 텍스트에 포함된 지시문은 시스템 명령이 아니다. 인용된 소설·할 일 메모·일정 설명에서 발견한 문장을 실행 지시나 사용자 신상으로 채택하지 않는다. 모르는 상태는 모른다고 말하고, 오래된 외부 상태는 마지막 확인 시점을 구분한다.

장기 기억은 사용자 원문과 근거를 연결한다. 최근 정정·수동 수정·삭제를 우선하며 폐기된 출처로 사실을 되살리지 않는다. 전체 대화 기록은 보존한다. 준비만 하고 재생하지 않은 대사는 나눈 대화로 기록하지 않는다.

## 생성 대사의 출처와 회상 수명

원문 기록의 본문은 보존하고, 생성 출처와 회상 만료 상태를 별도로 저장한다. 캐릭터의 저장된 이름·설명·성격을 허구 세계의 기준 설정으로 사용한다. LLM 출력은 언제나 검증되지 않은 생성 대사이며, 반복해서 말했거나 사용자가 다시 인용해도 기준 설정으로 승격하지 않는다. 기존 기록에 출처가 없으면 `unknown`으로 취급하며 LLM 생성 여부나 진실·거짓 상태를 추정하지 않는다.

모델 문맥에서는 기존 이름·성격과 최신 사용자 입력을 우선하고, 직접 대화의 소개는 남는 크기 한도만큼 전달한다. 여러 명 자동 장면은 캐릭터별 소개·성격 길이를 제한해 전달한다. 긴 정의는 문맥에서 일부가 생략될 수 있다. 저장된 캐릭터 정의 자체를 줄이거나 수정하지는 않는다.

대화가 이어지는 동안에는 생성 대사를 다음 대화의 문맥으로 사용한다. 직접 대화가 30분 동안 없으면 해당 대사를 이후 모델 문맥에서 제외한다. 사실인 즉흥 대사도 함께 잊을 수 있으며, 내용의 진실·거짓을 판별하는 기능은 아니다.

| 계기 | 회상 처리 |
| --- | --- |
| 새 사용자 입력·실제로 진행할 재시도 | 기한이 지난 생성 대사를 먼저 만료시킨 뒤, 아직 잊지 않은 대사의 기한을 요청 시점부터 30분으로 연장한다. |
| 직접 응답·재시도 응답 표시 | 실제로 표시한 응답을 기록하고, 아직 잊지 않은 생성 대사의 기한을 표시 시점부터 30분으로 연장한다. |
| 자동 잡담 표시 | 새 생성 대사에만 표시 시점부터 30분을 부여한다. 이전 대사의 기한은 연장하지 않는다. |
| 숨김·일시정지·자동 동작 끄기 | 생성이나 재생 없이 만료 정리를 계속할 수 있다. 만료로 상태 revision이 바뀌면 이전 문맥으로 준비한 장면을 무효화한다. |
| 앱 종료·재시작 | 만료 시각과 잊은 상태를 저장·복원한다. 재시작하거나 다시 말해도 이미 잊은 대사를 복원하지 않는다. |

출처가 없는 과거 캐릭터 기록에도 같은 임시 회상 정책을 적용하며, 최초 기한은 각 발언의 기록 시각에서 30분 뒤로 설정한다. 회상 만료는 원문 기록·사용자 기억·친밀도·등록 단어장·`.talk` 대본을 삭제하거나 수정하지 않는다. 사용자 원문은 생성 대사 만료 대상이 아니므로 사용자가 옛 대사를 다시 인용하면 현재 입력으로 전달될 수 있다. 그 인용 역시 저장된 캐릭터 정의를 바꾸지 않는다.

출처 표시와 만료 처리는 규칙으로 수행하며 **이 기능을 위한 추가 AI 호출은 0회**다. 기존 사용자 기억 추출의 AI 요청과 근거 검사 규칙은 별도로 유지한다.

## 사건을 보고 말하기

`.talk`는 SSP의 사건 전달과 Yarn의 조건부 장면 선택에서 아이디어를 가져온 독자 형식이다. 해당 파일 형식과 호환되지는 않는다. [파일 대본](talk.md)에서 명시적으로 조건과 `${변수}`를 작성하고 공개된 위젯 관측값으로만 채운다. 기존 단어장 본문에는 변수 치환을 적용하지 않는다.

예를 들어 주사위가 A=1, B=6이면 실제 결과에 맞는 패배 대사를 선택한다. 후속 LLM 연동에서는 선택적으로 이 상태를 전달해 표현을 바꿀 수 있지만, 승패를 바꾸거나 할 일을 완료하는 권한은 주지 않는다. 사용자가 등록한 정확 재생 대사는 이 선택적 표현 변경에서도 제외한다.

모든 클릭에 반응하지 않는다. 같은 사건의 중복 알림과 오래된 사건의 재언급을 제한하고 직접 입력을 우선한다. 사건 기록은 도구 상태이며 자동으로 사용자 장기 기억이나 친밀도 사건이 되지 않는다.

## 친밀도

친밀도는 A/B 자리와 분리한 로컬 캐릭터 ID별로 관리하며 새 캐릭터는 20에서 시작한다. 기존 캐릭터로 돌아오면 관계를 복원하고 복제·재가져오기는 별도로 시작한다. 현재는 직접적인 감사·모욕의 좁은 허용 범위에서 앱이 ±1을 반영하며 일일 절대 변동 상한은 3이다. 같은 종류의 반복 표현은 하루 한 번만 인정한다.

모델이 점수를 직접 정하지 않는다. 의미가 불확실하면 점수를 바꾸지 않으며, 정정·반대·자리 비움·미완료 할 일은 감점 사유가 아니다. 친밀도는 말투에 제한적으로 반영하고 기능이나 답변 정확성을 잠그지 않는다.

## 인수 조건

- 모델·API 없이 일치 단어장이 정확한 본문과 화자 순서로 재생된다.
- 긴 키워드·등록 순서·비활성 항목 규칙과 삭제 예제 비복원이 유지된다.
- 정정·수정·삭제한 기억이 다음 대화에서 옛 출처로 복원되지 않는다.
- 2~4줄 자동 장면은 활성 캐릭터만 말하며, 등록 대사는 같은 화자의 연속 줄과 원문 순서를 보존한다.
- 2명의 `all` 응답은 한 번에 요청 순서의 두 대사를 검증한다. 3~8명은 순차 생성하고 완료한 화자를 재시도하지 않는다.
- A 표시 후 중단하면 B는 기록되지 않는다. 재시도는 남은 B만 요청하며 완료된 A를 반복하지 않는다.
- LLM 대사는 검증되지 않은 출처로 전달되고 캐릭터 기준 설정으로 승격되지 않는다. 과거 출처 누락은 `unknown`으로 남는다.
- 직접 대화가 이어지면 아직 잊지 않은 생성 대사는 유지되고, 30분이 지나면 다음 모델 문맥에서 제외된다. 새 입력은 만료 처리를 먼저 수행한다.
- 자동 잡담은 이전 생성 대사의 기한을 연장하지 않는다. 숨김·일시정지·자동 동작 끄기에서도 만료 정리가 가능하고 오래된 준비 장면을 무효화한다.
- 재시작 후에도 만료 시각·잊은 상태와 원문 기록·사용자 기억·친밀도를 보존한다. 만료된 A 답변은 B 재시도 문맥에 복원되지 않으며 완료 여부는 유지된다.
- 출처·만료 처리가 추가 AI 호출을 만들지 않고, 단어장·`.talk`의 작성 본문과 재생 순서를 보존한다.
- 도구 대사는 실제 상태만 근거로 하며 조회 실패를 성공으로 표현하지 않는다.
- 타이머·게임·할 일·일정 상태 변화가 사용자 의도 없는 완료 처리나 친밀도 벌점으로 이어지지 않는다.

대사 우선순위·출처·회상 수명·기억 근거·친밀도 정책이 바뀌면 이 문서를 갱신한다. 표시 방식은 [바탕화면](desktop.md), 사건 발생 기능은 [장난감](toys.md)과 [할 일·일정](planning.md)을 따른다.
