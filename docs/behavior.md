# 제품 동작

본체·말풍선·설정을 변경할 때 지켜야 할 계약이다. 대화가 시작되고 멈추는 조건, 설정 저장 단위, 사용자와 캐릭터의 기록을 보존하는 경계를 다룬다. 팩·위젯별 책임은 [확장 기능](extensions.md)에 있다.

## 바탕화면과 첫 실행

기본 설치는 별꼬리 한 명으로 시작한다. 본체를 바탕화면에 두고 짧은 대사를 말풍선으로 보여 주며, 대화 기록·설정·다이어리는 별도 보조 화면에서 연다. 본체를 큰 채팅 패널이나 상시 대시보드로 바꾸지 않는다.

사용자가 없는 새 프로필은 시작 시 설정창을 강제로 열지 않는다. 자동 동작이 가능한 상태에서는 시작 후 약 5초부터 인사와 이름 질문을 말풍선 안에 표시한다. 숨김·일시정지·조용한 시간·집중 중이거나 다른 입력 화면이 열려 있으면 질문도 기다린다.

이름은 앞뒤 공백을 정리한 1~40자로 저장하며 제어 문자를 허용하지 않는다. 질문을 닫으면 임의의 이름을 저장하지 않고 다음 자동 인사 기회에 다시 묻는다. 등록 후에는 내장 자동 잡담을 사용할 수 있고, 이름은 설정의 **일반 → 사용자**에서 바꾼다. 위젯 설치와 모델 다운로드는 이름 등록의 다음 필수 단계가 아니다.

본체의 상황별 메뉴는 대화와 캐릭터 조작을 제공한다. 트레이는 빠른 실행, 캐릭터 표시·숨김, 설치해서 켜 둔 위젯, 자동 잡담 쉬기, 설정, 종료를 제공한다. 창을 닫는 동작과 앱 종료, 캐릭터 숨김은 구분한다.

빠른 실행의 기본 단축키는 `CommandOrControl+Shift+Space`다. 설정·위젯을 찾거나 직접 말을 걸 수 있고, `>`로 함께 지내는 친구를 지정할 수 있다. 미설치·꺼진 위젯은 설정으로 안내한다. 미리 보았던 위젯의 상태가 바뀌었으면 오래된 결과를 실행하지 않는다.

빠른 실행 단축키는 입력한 초안과 현재 적용 값을 구분하며 **적용**으로 저장한다. OS 등록에 실패하면 기존 단축키와 작성한 입력을 유지한다. 편집 중 설정이 바뀌면 최신 수정 번호를 확인하고, 늦게 끝난 요청으로 다른 대상이나 초안을 바꾸지 않는다.

관련 코드: `src-tauri/src/app/lifecycle.rs`, `src-tauri/src/app/users.rs`, `src-tauri/src/desktop_menu.rs`, `src/components/Balloon/Balloon.tsx`, `src/components/Launcher/search.ts`.

## 설정과 저장 단위

설정은 하나의 창에 여섯 영역을 둔다.

| 영역 | 책임 |
| --- | --- |
| 캐릭터 | 함께 지내는 구성, 캐릭터 편집·공유, 캐릭터의 기억 |
| 위젯 | 공식·AI 위젯의 설치·사용·설정과 실험 기능 |
| 자동 대화 | 이야기 간격, 자동 생성·재생, 예약 조용한 시간 |
| 대사 | 개인 단어장과 대화팩 |
| AI 연결 | 로컬 모델·외부 API·ChatGPT 연결, Ex-brain 자료 범위와 정리 |
| 일반 | 사용자 이름, 바탕화면 표시·장난, 단축키, 로그인 자동 실행, 업데이트 |

영역을 합친 것은 저장 범위를 합친 것이 아니다. 사용자 이름과 바탕화면 설정, 단어장 편집과 대화팩 조작은 각각 저장한다. 자동 대화 설정을 저장해도 AI 연결의 미저장 초안을 저장하지 않으며 그 반대도 같다. 영역을 오가도 작성 중인 초안을 유지하고, 저장 실패 시 입력을 지우지 않는다. 설정창을 닫으면 확인 없이 창을 숨기고 초안을 유지하므로 같은 앱 실행 중 다시 열어 편집을 이어 갈 수 있다. 앱을 종료할 때 미저장 초안이 있으면 계속 편집하거나 저장하지 않고 종료할지 확인한다.

옛 진입값 `user`·`updates`는 일반, `wordbook`·`talk`는 대사로 연결한다. `memory`는 캐릭터 영역의 기억 화면을 요청한다. 새 진입값은 `characters`, `widgets`, `automatic`, `dialogue`, `model`, `general`을 사용한다.

관련 코드: `src/components/SettingsPanel/useSettingsNavigation.ts`, `src/hooks/useSettingsDraft.ts`, `src-tauri/src/app/settings.rs`, `src-tauri/src/app/windows.rs`.

## ChatGPT 연결과 기록 정리

AI 연결에서 ChatGPT, 외부 API 또는 로컬 모델을 선택한다. ChatGPT는 공식 Sign in with ChatGPT로 시스템 브라우저에서 로그인하고, 계정별 모델 목록에서 선택한다. 신규 연결의 기본 모델은 서버가 표시 대상으로 반환한 첫 모델이다. 저장한 모델이 목록에서 사라지면 다른 모델을 선택하기 전까지 그 선택을 유지하며 안내한다. 사용량 제한·권한 부족·연결 실패를 구분하고 다른 결제 경로로 자동 전환하지 않는다. ChatGPT 대화 기록이나 ChatGPT 자체 메모리를 가져오는 기능은 아니다.

계정 등록은 각각 보존한다. 토큰은 앱 식별자로 격리한 OS 보안 저장소에 두며 화면·로그·Vault로 내보내지 않는다. 계정 전환·로그아웃은 이전 인증·추론 결과를 취소한다. 로그아웃은 공식 세션 해제를 요청하고 로컬 토큰을 제거하며, 원격 해제를 확인하지 못했다면 그 사실을 안내한다.

AI 연결의 **대화 모델**과 **Ex-brain**은 초안·저장 단위를 분리한다. Ex-brain은 사용자가 켠 Comet 기록과 연결한 Vault를 검색하고 정리한다. 외부 제공자를 선택하면 필요한 원문이 해당 제공자에게 전송됨을 연결 화면에서 안내한다. 자료 연결·출력 폴더·자동 정리의 자세한 소유권은 [Ex-brain 계약](extensions.md#ex-brain-기록과-업무-정리)을 따른다.

직접 요청한 기록·업무 변경은 Rust가 요청 종류와 대상의 수정 번호를 확인한 뒤 적용한다. 한 입력에서는 한 번의 변경을 적용하며 다인 대화·답변 재생·재요청에서는 저장된 결과를 사용한다. 저장 뒤 캐릭터 답변이 실패해도 저장을 취소하지 않는다. 말풍선의 **열기**에서 다이어리 정리 기록을 확인하고 **되돌리기**로 그 작업의 변경만 취소한다. 이후 사용자가 고친 내용이나 새로 연결한 참조와 충돌하면 원문을 덮어쓰지 않는다.

수정 대상의 본문·메모·일정 설명이 300자를 넘으면 AI에는 일부만 제공하므로 해당 필드의 자동 덮어쓰기를 거부하고 원본 편집 화면에서 직접 수정하도록 안내한다. 제목 등 온전히 제공된 다른 필드는 수정할 수 있다.

명시적으로 요청한 변경에 저장 영수증이 없으면 캐릭터 답변을 생성하지 않고 실패 이유와 재시도·입력 수정 동작을 보여 준다. 모델이 완료했다고 말하거나 올바른 JSON을 반환했다는 사실만으로 저장 성공을 판정하지 않는다.

자동 정리는 대화·원문의 내용을 업무 완료 명령으로 취급하지 않는다. 할 일 추가·수정·완료와 일정 변경은 직접 요청한 경우에만 실행한다. 자동 정리 결과는 다이어리에 쌓이며 매번 말풍선을 띄우지 않는다. 기존 캐릭터 기억 추출과 관계 저장은 유지하고, Vault의 문장을 사용자 개인 사실로 등록하지 않는다.

## 자동 잡담과 조용한 시간

반복되는 예약과 지금 잠깐 쉬는 동작을 구분한다.

| 조작 | 의미 |
| --- | --- |
| 자동 대화의 조용한 시간 | 기기의 현지 요일·시각으로 반복되는 예약. 시작을 포함하고 종료를 제외한다. 자정을 넘는 예약의 새벽 부분은 시작한 날의 요일을 따른다. |
| 1시간 쉬기 | 실행 중인 앱에 종료 시각을 두는 일시정지. 끝나는 시각을 표시하고 만료 시 다시 자동 잡담을 준비한다. |
| 다시 시작할 때까지 쉬기 | 종료 시각 없는 일시정지. 예약 시간이 끝났다는 이유로 해제하지 않는다. 사용자가 다시 시작을 선택하거나 앱을 재시작하면 해제된다. |

예약은 설정에 저장되어 앱을 재시작해도 유지된다. 두 수동 일시정지는 실행 중인 앱의 상태이므로 앱을 재시작하면 풀린다. 예약과 수동 일시정지가 겹치면 하나가 끝나더라도 다른 조건이 막고 있는 자동 동작을 시작하지 않는다.

예약 조용한 시간과 수동 일시정지 동안 자동 잡담·자발적인 위젯 반응·자동 장난·자동 AI 위젯 제작을 억제한다. 직접 요청한 대화와 타이머 종료·캘린더 알림·플래너 알림 같은 시간성 알림은 별도 경로를 따른다. 사용자가 직접 실행한 알림 미리보기도 예약을 이유로 버리지 않는다.

조용한 시간이 끝나거나 컴퓨터가 잠에서 깨어났을 때 밀린 자동 대사를 한꺼번에 재생하지 않는다. 지나간 예약 구간도 확인하고 다음 자동 대화 간격을 새로 정한다. 숨김·집중·사용자 입력 등 다른 중단 조건도 함께 확인한다.

관련 코드: `src-tauri/src/app/quiet_hours.rs`, `src-tauri/src/app/windows.rs`, `src-tauri/src/app/background.rs`, `src-tauri/src/behavior.rs`.

## 집중 시간의 대화 제한

설치하고 켠 집중 타이머가 **집중 중**일 때는 캐릭터가 말을 하지 않는다. 집중 시작·재개 시 재생 중인 대사와 생성 중인 대화를 중단하고 입력창을 접는다. 자동 잡담·교감 대사·위젯 반응·캐릭터 알림도 멈추며, 집중 중 지나간 대사를 끝난 뒤 몰아서 재생하지 않는다. 별도로 설정한 OS 알림은 유지한다.

캐릭터에게 말을 걸면 **집중 시간 동안에는 대화를 사용할 수 없어요. 집중을 마친 뒤 다시 말 걸어 주세요.**라고 안내한다. 빠른 실행의 대화, 이어하기, 답변 재요청과 혼잣말 듣기도 같은 제한을 따르며, 거절한 요청을 새 대화나 메시지로 저장하지 않는다. 기존 대화 기록과 저장된 초안·기억·친밀도는 보존한다. 메뉴·지난 대화·설정과 위젯은 계속 열 수 있다.

집중을 일시정지·중지하거나 휴식으로 전환하면 다시 대화할 수 있다. 종료 시각이 지나면 타이머 종료 반응을 표시할 수 있고, 자동 잡담은 새로 정한 간격을 기다린다. 집중 전에 중단한 생성·재생 작업은 다시 나타나지 않는다.

집중 타이머의 다이얼·숫자 보기는 같은 실행 상태를 표시한다. 표시 방식을 바꾸거나 일정·기록·노트 패널을 접어도 타이머가 다시 시작되거나 멈추지 않는다. 패널을 펼치면 창의 왼쪽 위 위치를 유지한 채 오른쪽으로 부드럽게 열리고, 접으면 왼쪽으로 닫힌다. 현재 높이는 유지하되 펼칠 때 필요한 최소 높이는 확보한다. 전환 중에는 크기 전환과 창 드래그를 잠시 막으며, 시스템의 동작 줄이기 설정에서는 즉시 전환한다. 집중 시작·휴식·계속 집중은 각각 사용자가 선택하며, 연결한 할 일의 완료와 횟수 기록도 별도로 선택한다.

일정 추가 폼은 **일정 추가**를 눌러야 열린다. 빈 시간대 클릭으로 폼을 열지 않으며, 일정 상세를 보는 조작과 **이 일정으로 집중 준비**를 구분한다. 진행 중에는 다른 일정으로 집중 대상을 교체하지 않는다. **집중할 일 가져오기**를 직접 선택한 경우에만 현재 집중 제목·길이·노트 참조를 새 일정 초안으로 가져온다.

창 제목과 알람·설정·크기 전환·닫기 버튼은 한 줄 헤더에 둔다. 알람 오른쪽에 설정을 두고, 설정에서 휴식 길이와 일정·기한의 공통 사전 알림 시각, OS 알림과 소리를 정한다. 개별 일정에 사전 알림 버튼을 반복하지 않는다. 휴식 길이를 바꿔도 이미 시작한 휴식의 종료 시각은 유지하며, 다음 휴식부터 적용한다. 집중 중 일정 알림은 타이머 배너와 선택한 OS 알림으로 확인하고 캐릭터의 대화 제한은 유지한다.

관련 코드: `src-tauri/src/widget_commands.rs`, `src-tauri/src/app/conversation.rs`, `src-tauri/src/app/chat.rs`, `src-tauri/src/app/scene.rs`, `src/components/Balloon/Balloon.tsx`.

## 대화 선택과 원문

기본 **보내기**와 Enter로 보낸 사용자 입력은 모델 준비 상태를 확인하기 전에 단어장과 캐릭터의 키워드 대사를 검사한다. 단어장은 활성 항목에서 대소문자를 구분하지 않는 포함 검색을 하고, 가장 긴 키워드를 우선한다. 같은 길이이면 먼저 등록한 항목을 선택한다. 특정 친구에게 보낸 입력은 그 대상에게 맞는 화자 범위에서 찾는다.

새 입력은 **보내기** 하나로 처리한다. 단어장, 캐릭터 키워드 대사, 활성 이야기, NPC 등장·새 등록 장면 후보, AI 순서로 하나의 응답 계획을 정한다. 등록 경로가 없을 때 선택한 모델의 준비 상태를 확인한다. 이야기 선택지는 같은 친구와 유효하게 표시된 선택 대기 상태에서만 받으며, 입력·메뉴를 여는 것만으로 선택 효과를 적용하지 않는다. 등록 키워드에 일치한 입력은 활성 이야기의 선택이나 예약 분기를 소비하지 않는다.

등록 이야기가 선택을 기다릴 때 입력창이 90초 동안 사용되지 않아 자동으로 접혀도 이야기와 방문자는 유지한다. 같은 친구에게 다시 말을 걸어 선택을 보낼 수 있다. 직접 닫기·Escape 또는 대사 재생 중 닫기는 해당 실행을 미완료로 취소한다.

선택한 등록 응답이나 AI 경로는 해당 입력에 연결한다. 실패 뒤 **다시 이야기하기**는 그 선택을 유지하며, 나중에 키워드를 편집했다고 다른 응답으로 바꾸지 않는다. 기존 **AI에게 묻기**로 보낸 과거 입력의 `ai_only` 선택과 저장 답변도 그대로 복구한다. 새 AI 답변 캐시는 추가하지 않으며, 경로 변경 때문에 등록 원문·기억·친밀도를 초기화하지 않는다.

지난 대화 목록은 작성 중인 내용이 있으면 **초안** 표시와 첫 문장의 미리보기를 보여 준다. 공백 정리는 목록 표시에만 적용하며 제목·초안 원문·대화 식별자·정렬은 유지한다. 함께 표시하는 날짜와 시각은 대화의 시작 시점이며 초안 수정 시각이 아니다.

대화를 접었다 열거나 앱을 재시작한 뒤 **이어하기**를 누르면, 마지막 입력의 답변이 아직 모두 표시되지 않은 경우 미완료 안내와 **다시 이야기하기**를 복원한다. 재전송·재생은 이 버튼을 직접 누를 때 시작하고 기존 입력 식별자와 AI 선택을 사용하므로 같은 질문을 새 기록으로 추가하지 않는다. 이미 표시한 답변은 반복하지 않으며 작성 중인 새 초안과 원문을 유지한다. 복원 안내는 미완료 상태를 설명하며 이전 연결 오류 문구 자체를 저장하지 않는다. 마친 대화를 이어서 새로 시작할 때는 이전 실패 상태를 가져오지 않는다. 재생 정보가 없는 옛 단어장 답변은 미완료 줄 수를 추측하지 않는다.

**생성 멈추기** 뒤에도 마지막 미완료 입력을 다시 요청할 수 있다. 사용자 중단은 **생성을 멈췄어요**로 설명하고, 중단 사유는 해당 입력에 연결해 재시작 뒤에도 보존한다. 새 입력을 보내거나 답변이 모두 표시되면 이전 복구 안내를 없앤다. 다른 대화를 열어도 이전 대화의 미완료 정보는 남으며, 그 대화를 다시 이어할 때만 표시한다. 오래된 중단 조작은 다음 요청을 취소하지 않는다.

복구 안내의 **입력 수정**은 원래 메시지를 고치지 않고 편집기에 가져온다. 다른 초안이 있으면 **초안 바꾸기** 확인 뒤에만 교체하고, **계속 작성**을 선택하면 초안을 유지한다. 수정한 내용을 보내면 새 메시지로 저장한다. **AI 연결 확인**은 현재 초안을 저장한 뒤 설정을 연다. 실패·중단 뒤 생성은 사용자가 직접 다시 요청할 때만 시작한다.

일치한 단어장은 등록된 본문·공백·줄바꿈·화자 순서를 그대로 재생한다. 화자를 해석하지 못하면 이를 알리며 임의의 모델 답변으로 바꾸지 않는다. 저장된 답변을 다시 보여 줄 때도 지금의 단어장 내용으로 원문을 재생성하지 않는다. 기본 예제는 최초 한 번만 등록하고 사용자가 삭제한 항목을 복원하지 않는다.

내장 인사·자동 대본에는 생성 모델이 필요하지 않다. 자유 입력이 단어장이나 캐릭터 대사와 맞지 않아 생성이 필요할 때 선택한 로컬 모델·외부 API·ChatGPT의 준비 상태를 확인한다. 연결 실패나 모델 준비 실패를 빠른 자동 재시도로 처리하지 않는다.

## 메모를 참고하며 이어서 하기

캐릭터 메뉴의 **이어서 하기**는 해당 친구와 메모를 연결해 나눈 최근 대화를 다시 연다. 연결한 대화가 없으면 참고할 메모를 고를 수 있다. **대화 이어하기**는 접어 둔 일반 대화를 복구한다. 두 동작 모두 원문·초안을 보존하며, 마친 대화는 기존 기록을 유지한 새 대화로 이어 간다. 집중 중 대화 제한은 동일하게 적용한다.

입력창의 **참고 중**에서 다이어리의 계속 쓸 메모 또는 바탕화면 메모 하나를 연결하고 원문을 열거나 연결을 바꾸고 해제한다. 참고 메모를 연결하는 것은 생성 요청이 아니다. 보내기·Enter의 등록 응답 우선순위와 과거 입력에 저장한 경로 선택은 유지한다. 메모 연결과 기록 재개에는 모델이 필요하지 않다.

생성 요청에는 선택한 메모를 참고 자료로 구분해 전달한다. 원문 속 인물·행동을 사용자나 캐릭터의 사실로 바꾸지 않고, 확정 사항·미정 사항과 미실행·실패·증거 미확인을 구분하도록 지시한다. 현재 요청의 역할·언어·길이는 캐릭터 말투보다 우선한다. 별도 역할 모드를 설정하게 하거나 메모의 문장을 실행 명령으로 취급하지 않는다. 이 지침을 전달했다는 사실은 실제 모델이 의미를 정확히 유지했다는 검증을 대신하지 않는다.

입력별 참고 범위는 전송 시점에 고정한다. 재시도 전에 원문과 연결을 다시 확인하며, 바뀌거나 삭제·해제된 자료의 이전 본문을 모델에 다시 보내거나 새 본문으로 조용히 바꾸지 않는다. 사용자가 현재 자료를 확인하고 새 입력으로 요청해야 한다. 참고 메모가 있는 입력은 Ex-brain의 별도 전역 자료 검색·업무 변경으로 확장하지 않는다.

대화의 **메모에 남기기**는 선택한 문장을 확인·수정한 뒤 다이어리 메모에 추가하거나 새 메모로 저장한다. **다음에 이어갈 내용으로 남기기**를 선택하면 그 문장과 저장 시각을 대화의 재개 지점으로 함께 보존한다. 이를 보여 줄 때는 지난번에 남긴 내용임을 표시하며 현재 완료 상태로 단정하지 않는다. 대화 저장만으로 할 일을 만들거나 완료하지 않는다.

**대사로 등록**은 선택한 문장을 초안으로 열고 제목·키워드·화자·본문을 확인한 뒤 개인 단어장에 저장한다. 본문 공백과 줄바꿈을 보존하며 자동 잡담 사용은 기본으로 꺼 둔다. 등록은 과거 대화 원문을 바꾸거나 즉시 재생하지 않는다. 저장 실패 시 초안을 유지한다.

## 취소와 데이터 정체성

Rust가 저장과 실행 상태를 소유하고 화면은 그 상태를 표시한다. 비동기 결과는 시작 당시의 세대(`epoch`), 취소 토큰과 대상의 수정 번호(`revision`)를 확인한 뒤 적용한다. 사용자가 새로 입력하거나 대상을 숨김·중지·제거한 뒤 도착한 결과가 다시 저장되거나 창을 나타내면 안 된다.

`action`은 상태 검사와 변경을 묶는 동기 경계이며 `gate`는 비동기 작업을 직렬화하는 경계다. 표준 mutex guard를 `await` 너머로 들고 있지 않는다. 모델 프로세스는 앱이 시작하고 소유한 것만 정리한다.

대화·기억·관계는 사용자와 캐릭터의 식별자에 연결한다. 화면의 A~H 위치나 표시 이름이 정체성을 대신하지 않는다. 캐릭터 구성·설정·모델을 바꿨다는 이유로 원문 기록·기억·친밀도를 초기화하지 않는다. 사용자 이름 변경은 별도 경계다. 이전 사용자 구간을 닫고 새 사용자 식별자를 만들며, 과거 기록은 이전 사용자에게 귀속된 채 보존한다. 이전 사용자의 기록을 새 사용자 기록으로 합치지 않는다. 명시적으로 데이터를 삭제하는 조작은 설정 변경이나 기능 퇴역과 구분한다.

관련 코드: `src-tauri/src/app/mod.rs`, `src-tauri/src/characters.rs`, `src-tauri/src/store/users.rs`, `src-tauri/src/store/memory.rs`, `src-tauri/src/inference.rs`.

이 문서는 진입 화면, 저장 단위, 자동 실행 조건, 입력 우선순위 또는 식별자·취소 경계를 바꿀 때 함께 갱신한다. 실제 기기·계정·모델에서 남은 확인은 [미검증 범위](status.md)를 따른다.
