# 제품 동작

본체·말풍선·설정을 변경할 때 지켜야 할 계약이다. 대화가 시작되고 멈추는 조건, 설정 저장 단위, 사용자와 캐릭터의 기록을 보존하는 경계를 다룬다. 팩·위젯별 책임은 [확장 기능](extensions.md)에 있다.

## 바탕화면과 첫 실행

기본 설치는 별꼬리 한 명으로 시작한다. 본체를 바탕화면에 두고 짧은 대사를 말풍선으로 보여 주며, 대화 기록·설정·다이어리는 별도 보조 화면에서 연다. 본체를 큰 채팅 패널이나 상시 대시보드로 바꾸지 않는다.

사용자가 없는 새 프로필은 시작 시 설정창을 강제로 열지 않는다. 자동 동작이 가능한 상태에서는 시작 후 약 5초부터 인사와 이름 질문을 말풍선 안에 표시한다. 숨김·일시정지·조용한 시간·집중 중이거나 다른 입력 화면이 열려 있으면 질문도 기다린다.

이름은 앞뒤 공백을 정리한 1~40자로 저장하며 제어 문자를 허용하지 않는다. 질문을 닫으면 임의의 이름을 저장하지 않고 다음 자동 인사 기회에 다시 묻는다. 등록 후에는 내장 자동 잡담을 사용할 수 있고, 이름은 설정의 **일반 → 사용자**에서 바꾼다. 위젯 설치와 모델 다운로드는 이름 등록의 다음 필수 단계가 아니다.

본체의 상황별 메뉴는 대화와 캐릭터 조작을 제공한다. 트레이는 빠른 실행, 캐릭터 표시·숨김, 설치해서 켜 둔 위젯, 자동 잡담 쉬기, 설정, 종료를 제공한다. 창을 닫는 동작과 앱 종료, 캐릭터 숨김은 구분한다.

빠른 실행의 기본 단축키는 `CommandOrControl+Shift+Space`다. 설정·위젯을 찾거나 직접 말을 걸 수 있고, `>`로 함께 지내는 친구를 지정할 수 있다. 미설치·꺼진 위젯은 설정으로 안내한다. 미리 보았던 위젯의 상태가 바뀌었으면 오래된 결과를 실행하지 않는다.

관련 코드: `src-tauri/src/app/lifecycle.rs`, `src-tauri/src/app/users.rs`, `src-tauri/src/desktop_menu.rs`, `src/components/Balloon/Balloon.tsx`, `src/components/Launcher/search.ts`.

## 설정과 저장 단위

설정은 하나의 창에 여섯 영역을 둔다.

| 영역 | 책임 |
| --- | --- |
| 캐릭터 | 함께 지내는 구성, 캐릭터 편집·공유, 캐릭터의 기억 |
| 위젯 | 공식·AI 위젯의 설치·사용·설정과 실험 기능 |
| 자동 대화 | 이야기 간격, 자동 생성·재생, 예약 조용한 시간 |
| 대사 | 개인 단어장과 대화팩 |
| AI 연결 | 선택한 로컬 모델 또는 외부 API |
| 일반 | 사용자 이름, 바탕화면 표시·장난, 단축키, 로그인 자동 실행, 업데이트 |

영역을 합친 것은 저장 범위를 합친 것이 아니다. 사용자 이름과 바탕화면 설정, 단어장 편집과 대화팩 조작은 각각 저장한다. 자동 대화 설정을 저장해도 AI 연결의 미저장 초안을 저장하지 않으며 그 반대도 같다. 영역을 오가도 작성 중인 초안을 유지하고, 저장 실패 시 입력을 지우지 않는다. 설정창을 닫으면 확인 없이 창을 숨기고 초안을 유지하므로 같은 앱 실행 중 다시 열어 편집을 이어 갈 수 있다. 앱을 종료할 때 미저장 초안이 있으면 계속 편집하거나 저장하지 않고 종료할지 확인한다.

옛 진입값 `user`·`updates`는 일반, `wordbook`·`talk`는 대사로 연결한다. `memory`는 캐릭터 영역의 기억 화면을 요청한다. 새 진입값은 `characters`, `widgets`, `automatic`, `dialogue`, `model`, `general`을 사용한다.

관련 코드: `src/components/SettingsPanel/useSettingsNavigation.ts`, `src/hooks/useSettingsDraft.ts`, `src-tauri/src/app/settings.rs`, `src-tauri/src/app/windows.rs`.

## 자동 잡담과 조용한 시간

반복되는 예약과 지금 잠깐 쉬는 동작을 구분한다.

| 조작 | 의미 |
| --- | --- |
| 자동 대화의 조용한 시간 | 기기의 현지 요일·시각으로 반복되는 예약. 시작을 포함하고 종료를 제외한다. 자정을 넘는 예약의 새벽 부분은 시작한 날의 요일을 따른다. |
| 1시간 쉬기 | 실행 중인 앱에 종료 시각을 두는 일시정지. 끝나는 시각을 표시하고 만료 시 다시 자동 잡담을 준비한다. |
| 다시 시작할 때까지 쉬기 | 종료 시각 없는 일시정지. 예약 시간이 끝났다는 이유로 해제하지 않는다. 사용자가 다시 시작을 선택하거나 앱을 재시작하면 해제된다. |

예약은 설정에 저장되어 앱을 재시작해도 유지된다. 두 수동 일시정지는 실행 중인 앱의 상태이므로 앱을 재시작하면 풀린다. 예약과 수동 일시정지가 겹치면 하나가 끝나더라도 다른 조건이 막고 있는 자동 동작을 시작하지 않는다.

예약 조용한 시간과 수동 일시정지 동안 자동 잡담·자발적인 위젯 반응·자동 장난·자동 AI 위젯 제작을 억제한다. 직접 요청한 대화와 타이머 종료·캘린더 알림·플래너 알림 같은 시간성 알림은 별도 경로를 따른다. 사용자가 직접 실행한 알림 미리보기도 예약을 이유로 버리지 않는다.

조용한 시간이 끝나거나 컴퓨터가 잠에서 깨어났을 때 밀린 자동 대사를 한꺼번에 재생하지 않는다. 지나간 예약 구간도 확인하고 다음 자동 대화 간격을 새로 정한다. 숨김·집중·사용자 입력 등 다른 중단 조건도 함께 확인한다.

관련 코드: `src-tauri/src/app/quiet_hours.rs`, `src-tauri/src/app/windows.rs`, `src-tauri/src/app/background.rs`, `src-tauri/src/behavior.rs`.

## 대화 선택과 원문

기본 **보내기**와 Enter로 보낸 사용자 입력은 모델 준비 상태를 확인하기 전에 단어장과 캐릭터의 키워드 대사를 검사한다. 단어장은 활성 항목에서 대소문자를 구분하지 않는 포함 검색을 하고, 가장 긴 키워드를 우선한다. 같은 길이이면 먼저 등록한 항목을 선택한다. 특정 친구에게 보낸 입력은 그 대상에게 맞는 화자 범위에서 찾는다.

말풍선의 **AI에게 묻기**는 이번 입력만 개인 단어장과 캐릭터 키워드 매칭을 건너뛰고 선택한 모델로 보낸다. 모델·API 준비가 필요한 경우 이 버튼은 비활성화하고 AI 연결 설정을 안내하며, 기본 보내기는 계속 사용할 수 있다. 이 선택은 해당 입력과 함께 저장하므로 실패 뒤 **다시 이야기하기**에도 유지한다. 앱 재시작·업그레이드로 저장한 선택을 바꾸지 않는다. 다음 입력의 기본 보내기에는 적용하지 않으며, 선택 때문에 등록 원문·키워드·기억·친밀도를 초기화하거나 재작성하지 않는다.

일치한 단어장은 등록된 본문·공백·줄바꿈·화자 순서를 그대로 재생한다. 화자를 해석하지 못하면 이를 알리며 임의의 모델 답변으로 바꾸지 않는다. 저장된 답변을 다시 보여 줄 때도 지금의 단어장 내용으로 원문을 재생성하지 않는다. 기본 예제는 최초 한 번만 등록하고 사용자가 삭제한 항목을 복원하지 않는다.

내장 인사·자동 대본에는 생성 모델이 필요하지 않다. 자유 입력이 단어장이나 캐릭터 대사와 맞지 않아 생성이 필요할 때 선택한 로컬 모델 또는 API의 준비 상태를 확인한다. 연결 실패나 모델 준비 실패를 빠른 자동 재시도로 처리하지 않는다.

관련 코드: `src-tauri/src/wordbook.rs`, `src-tauri/src/app/conversation.rs`, `src-tauri/src/app/scene.rs`, `src-tauri/src/talk_host.rs`.

## 취소와 데이터 정체성

Rust가 저장과 실행 상태를 소유하고 화면은 그 상태를 표시한다. 비동기 결과는 시작 당시의 세대(`epoch`), 취소 토큰과 대상의 수정 번호(`revision`)를 확인한 뒤 적용한다. 사용자가 새로 입력하거나 대상을 숨김·중지·제거한 뒤 도착한 결과가 다시 저장되거나 창을 나타내면 안 된다.

`action`은 상태 검사와 변경을 묶는 동기 경계이며 `gate`는 비동기 작업을 직렬화하는 경계다. 표준 mutex guard를 `await` 너머로 들고 있지 않는다. 모델 프로세스는 앱이 시작하고 소유한 것만 정리한다.

대화·기억·관계는 사용자와 캐릭터의 식별자에 연결한다. 화면의 A~H 위치나 표시 이름이 정체성을 대신하지 않는다. 캐릭터 구성·설정·모델을 바꿨다는 이유로 원문 기록·기억·친밀도를 초기화하지 않는다. 사용자 이름 변경은 별도 경계다. 이전 사용자 구간을 닫고 새 사용자 식별자를 만들며, 과거 기록은 이전 사용자에게 귀속된 채 보존한다. 이전 사용자의 기록을 새 사용자 기록으로 합치지 않는다. 명시적으로 데이터를 삭제하는 조작은 설정 변경이나 기능 퇴역과 구분한다.

관련 코드: `src-tauri/src/app/mod.rs`, `src-tauri/src/characters.rs`, `src-tauri/src/store/users.rs`, `src-tauri/src/store/memory.rs`, `src-tauri/src/inference.rs`.

이 문서는 진입 화면, 저장 단위, 자동 실행 조건, 입력 우선순위 또는 식별자·취소 경계를 바꿀 때 함께 갱신한다. 실제 기기·계정·모델에서 남은 확인은 [미검증 범위](status.md)를 따른다.
