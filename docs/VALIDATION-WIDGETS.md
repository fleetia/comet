# 공식 위젯 구현 검증 기록

2026-09-15 공식 위젯 22개·선택 설치·로컬 저장·읽기 연결 작업의 검증 기록이다. 아래 결과는 현재 작업 소스에 대한 것이며 [0.2.0](VALIDATION-0.2.0.md)·[0.3.0](VALIDATION-0.3.0.md)의 과거 관찰을 새 결과로 재사용하지 않는다. 병행 작업으로 바뀌는 전체 소스의 결과는 실행 시점별로 구분한다. 아래 시각은 KST다.

## 소스 범위

- `widgets/catalog.json`: 22개 공식 manifest. 설치는 사용자 데이터의 `widgets/`에 manifest를 등록하며 기능 코드는 공용 Rust 호스트·프론트엔드에 포함된다.
- `src-tauri/src/widgets/`: 설치·상태 전이·투두·놀이·캘린더·정보 연결·일정 알림.
- `src-tauri/src/widget_commands.rs`, `widget_connections.rs`: 사용자 명령·작업 취소·현재 revision 확인·OS 자격 증명 저장·공용 말풍선.
- `src/widgets/`: 각 도구의 입력·조회·명시적 동작, 연결 실패·의존성·데이터 보존 안내.

공식 위젯 구현과 외부 Widget SDK·임의 코드 실행·원격 패키지 배포는 별개다. 외부 확장은 아직 제공하지 않는다.

## 자동 검증

| 검사 | 명령 또는 범위 | 현재 기록 |
| --- | --- | --- |

| 최신 준비 봉투·투두 UI 집중 검증 | `pnpm exec vitest run src/widgets/__tests__/PreparationTodo.test.tsx` | 5개 통과. 루틴·목록 필터, 연결 끊김과 링크 opener, KST 01:00 이월, DST 존재하지 않는 시각 거부 |

캘린더 테스트는 실제 loopback HTTP 서버의 ICS 응답 읽기·크기 제한, 반복 회차 이동/취소·DST·종일 일정, PKCE/state 검증과 공개 스냅샷의 비밀정보 제외를 포함한다. 이 자동 검증은 Google 실계정 동의의 증거가 아니다. 별도 네이티브 ICS 연결에서 OS Keychain 저장 성공을 관찰했다.

새 ad-hoc 빌드로 재실행할 때 Keychain 읽기가 OS 권한 확인을 기다리는 현상을 발견했다. 읽기를 별도 스레드 최대 2개로 제한하고 대기 포함 5초가 지나면 인증 오류로 표시하도록 수정했다. 지연된 결과는 폐기하고 자동 재시도를 멈춘다. 회귀 테스트는 대기 중인 읽기·추가 스레드 생성 제한·읽기 복구를 실제 자격 정보 없이 검증한다. OS 동기 호출 자체는 취소할 수 없으며, 권한 확인 또는 프로세스 종료까지 제한된 작업이 남을 수 있다.

설치 저장 테스트는 manifest 검증·잘못된 경로 거부·실패 rollback·재설치와 데이터 보존·요청 중복 방지·stale revision 거부를 다룬다. UI mock은 실제 IPC 계약과 맞춘다. `WidgetEvent`는 `serde(flatten)`을 사용하므로 JSON의 사건 본문은 최상위 `text`이며, 실제 `serde_json::to_value`로 검증했다.

## UI 구현과 디자인 검증

위젯 구현 당시 Lagrange 0.2.2 컴포넌트·테마로 전환했으며, 당시에는 Figma 탭 접근 제한으로 시각 동기화를 마치지 못했다. 이후 2026-09-16 디자인 정리에서 공통 테마·글꼴 역할·구분선을 맞추고 관리 화면과 도구의 조작 순서를 재구성했다. 자동 검사와 브라우저 검증은 [위젯 UI 검증](status.md#위젯-ui-검증)에 실행 범위를 기록한다.

기존 Figma [관리 화면](https://www.figma.com/design/vKl8h9uoXUUljJ5yEAcNpr?node-id=81-6279)과 [개별 도구](https://www.figma.com/design/vKl8h9uoXUUljJ5yEAcNpr?node-id=81-6320)에 설치됨·추가 탭 및 할 일·타이머·승부·날씨의 대표 배치를 반영하고 브라우저 화면과 대조했다. 편집 가능한 SVG 배치와 일부 Library 버튼 인스턴스를 사용했다. 22개 도구의 모든 상태를 Figma에 옮기거나 모든 요소의 컴포넌트·변수 binding을 검증한 결과는 아니다.

## 미검증과 제한

- Google 실제 계정 OAuth 동의·access/refresh token 갱신·해제는 미검증이다. ICS의 OS Keychain 저장 성공과 구분한다. 실제 절전·복귀와 음악 곡 정보도 확인하지 못했다.
- Windows 네이티브 설치·실행·배터리·복귀 관찰은 수행하지 않았다. macOS 전용 음악 연결을 Windows 지원으로 표시하지 않는다.
- 비공개 실사용 구독 URL·토큰·계정 정보는 테스트 fixture와 이 기록에 넣지 않는다.
- ICS 지원 형식, -30일~+365일 조회, 4 MiB·5000개 한도, 갱신·backoff와 기본 알림 정책은 [생활 도구 계약](product/planning.md)을 따른다.
- 장시간 CPU·메모리·배터리·다중 모니터·전수 접근성·LLM 의미 품질은 자동 테스트 통과만으로 확인되지 않는다.
- 설치 바이트 수는 manifest 크기다. 전체 앱 실행 코드·메모리 사용량 또는 제거 시 절약 용량으로 해석하지 않는다.
