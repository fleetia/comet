# 위젯 선택 설치와 제거

**상태: 공식 위젯 22개의 선택 설치·추가·중지·제거를 구현했다.** 이 문서는 현재 공식 패키지의 동작을 설명한다. 실제 검증은 [위젯 검증 기록](../VALIDATION-WIDGETS.md)을 따른다. 설치할 기능은 [위젯 카탈로그](catalog.md), 실행 중 취소와 발화는 [수명주기](lifecycle.md)를 따른다.

Comet 본체만으로 A/B와 대화할 수 있어야 한다. 사용자가 선택한 위젯만 설치·활성화하며, 미설치 위젯의 예약·외부 연결·화면을 실행하지 않는다. 위젯 선택과 LLM 모델 다운로드는 별개다.

## 처음 설치할 때

앱의 첫 위젯 선택 화면에서 항목을 고르거나 모두 건너뛴다. 이후에도 같은 관리 화면에서 설치한다. 운영체제 설치 마법사의 구성 요소 선택은 제공하지 않는다.

1. 캐릭터와 기본 수다를 바로 사용할 수 있게 하고, 처음 한 번 위젯 선택 화면을 제공한다.
2. 각 위젯의 기능·필요한 연결·의존성을 보여 준다. 현재 관리 화면에는 설치 용량을 표시하지 않는다.
3. 분류와 개별 선택으로 필요한 항목만 고른다. 모두 건너뛰어도 된다.
4. 사용자가 최종 선택한 항목과 필요한 의존성을 확인한 뒤 설치한다. 캘린더 계정 연결은 해당 위젯 설정에서 진행한다.
5. 선택 화면을 닫으면 작은 A/B와 사용자가 꺼낸 도구만 남는다. 관리 화면이 상시 배경으로 남지 않는다.

건너뛴 초기 설정을 매번 다시 열지 않는다. 앱 업데이트가 새 위젯을 자동 설치하거나 사용자가 제거한 항목을 복원하지 않는다.

## 나중에 관리할 때

캐릭터 메뉴 또는 트레이의 **위젯 관리**에서 카탈로그와 설치된 항목을 확인한다. 공식 카탈로그 선택과 향후 외부 ZIP 가져오기는 같은 설치 상태 관리에 연결한다. 공개 마켓플레이스나 원격 자동 업데이트 서비스는 별도 후속 범위다.

| 사용자 동작 | 결과 |
| --- | --- |
| 설치 | 패키지를 검사하고 설치 상태를 저장한다. 필요한 연결·권한이 준비되면 사용할 수 있다. |
| 꺼내기·화면 닫기 | 표시 여부만 바꾼다. 켜 둔 타이머 등 필요한 예약은 유지한다. |
| 끄기 | 패키지·사용자 데이터는 보존하고 예약·연결 작업·자동 반응을 중지한다. |
| 다시 켜기 | 현재 상태를 확인해 실행을 재개한다. 꺼져 있던 동안의 알림을 몰아서 재생하지 않는다. |
| 제거 | 작업·화면·대기 대사를 중지하고 설치 등록과 설치된 패키지 파일을 정리한다. |
| 재설치 | 남겨 둔 데이터를 호환성 검사 후 사용할 수 있다. 오래된 사건을 새 사건으로 재생하지 않는다. |

`미설치`, `설치됨·꺼짐`, `켜짐`, `설정 필요`, `설치 실패`를 구분한다. 화면이 열려 있는지는 별도 상태다. 설정이 필요한 위젯을 실행 중인 것처럼 표시하지 않는다.

## 관리 화면과 개별 도구

2026-09-16 UI 정리는 설치·저장·권한 계약을 유지하면서 자주 하는 작업을 먼저 보이도록 배치한다. Lagrange의 제목·본문·숫자 글꼴 역할과 구분선을 모든 위젯에 적용한다.

관리 화면은 **설치됨**과 **추가할 위젯** 탭으로 나눈다. 설치된 항목에서는 꺼내기·켜기·설정 열기를 먼저 제공하고, **확인 필요**로 연결이나 설치 문제가 있는 항목을 모아 본다. 추가할 항목은 생활 도구·장난감·외부 연결로 찾는다. 탭을 바꿔도 설치할 선택은 유지하며, 아직 설치하지 않은 선택이 있으면 안내 없이 초기 설정을 끝내지 않는다.

2026-09-19 개별 도구 창은 제목 위의 생활 도구·장난감·외부 연결 표기와 **위젯 관리** 버튼을 제거한다. 제목과 닫기(×)만 한 줄의 고정 헤더에 두고 본문만 스크롤한다. 내용과 독립된 생성·전체 정리 조작은 오른쪽 아래의 고정 영역에 둔다. 이 하단 영역에 별도 테두리나 박스를 추가하지 않으며, 해당 조작이 없으면 빈 영역을 만들지 않는다. 관리 화면은 캐릭터 메뉴나 트레이에서 연다. 공통 창 구조와 드래그 경계는 [창 이동과 닫기](../product/desktop.md#창-이동과-닫기)를 따른다.

메모 생성, 공·비행기·비눗방울·펫의 **바탕화면에 꺼내기**·**정리하기**, 수집함의 **소품 모두 넣기**를 하단 고정 조작으로 제공한다. 타이머 실행·일시정지, 폼 저장, 항목별 수정·삭제, 놀이의 상태 조작은 관련 본문에 둔다. 일지·연결 도구의 새로고침도 조회 결과와 가까운 본문에 유지한다. 날씨의 지역 변경, 음악 연결, 준비 봉투의 자료·할 일 연결은 필요할 때 펼친다. 캘린더는 일정 뒤에 알림과 연결 설정을 둔다. 연결되지 않은 도구는 필요한 설정을 바로 보여 준다.

시계·기념일, 날씨, 기기 소식은 개별 도구 본문에서 표시 설정을 펼쳐 바탕화면 표시를 꾸밀 수 있다. **바탕화면에 꺼내기**는 설정 창 하단에서 별도 표시 창을 열고, 표시 닫기는 창만 닫는다. 배경 이미지·색상, 이미지 위치와 글자 위치를 저장할 때 기념일·연결 데이터는 함께 초기화하지 않는다.

할 일은 제목만으로 빠르게 추가하고 메모·목록·기한·반복을 펼쳐 지정한다. 선택한 값은 접힌 상태에서도 요약해서 보여 준다. 수정할 때 입력란으로 이동하며, 접힌 입력란에 오류가 있으면 펼쳐 확인할 수 있다. 할 일·기념일은 수정 취소로 작성 화면을 초기화하고, 저장 실패 시 입력한 초안을 보존한다. 메모는 목록의 오른쪽 아래 **+ 새 메모**로 낱장을 만들고, 저장된 항목을 꺼내 독립된 창에서 편집한다. 저장과 창 수명은 [낱장 메모](../product/planning.md#낱장-메모)를 따른다.

브라우저 미리보기의 예시 데이터는 실제 계정·저장 상태와 분리한다. 입력과 화면 이동을 확인할 수 있으며 저장·실행·외부 연결은 데스크톱 앱에서 수행한다.

## 의존성과 데이터

필수 의존성과 선택 연동은 [카탈로그](catalog.md)에 구분한다. 집중 타이머는 혼자 사용할 수 있고 투두가 있을 때만 할 일을 연결한다. 준비 봉투에 필요한 캘린더가 없으면 함께 설치할 항목을 안내한다. 의존성을 사용자 선택에 포함시키지 않은 채 추가하지 않는다.

다른 위젯이 필요로 하는 항목을 제거할 때는 영향을 받는 기능을 먼저 보여 준다. 의존 위젯의 연결 기능은 멈추고 `설정 필요`로 표시한다. 다른 위젯을 자동으로 함께 제거하지 않는다. 켜져 있는 준비 봉투는 의존성이 없어도 다시 열어 로컬 체크리스트와 자료를 편집할 수 있다. 캘린더 제거로 로컬 준비물이나 투두를 지우지 않는다.

제거의 기본값은 **사용자 작성 데이터 보존**이다. 위젯 고유 데이터까지 지우는 선택은 삭제 범위를 분명히 보여 준다. 투두·대화·기억·단어장 같은 Comet 공통 데이터는 다른 위젯 제거의 삭제 대상에 포함하지 않는다. 연결과 자격 증명은 소유 범위를 확인해 정리하고, 다른 설치 항목에서 사용하는 연결을 함께 없애지 않는다.

## 첫 구현의 패키지 범위

`widgets/catalog.json`의 공식 manifest 목록을 앱에 동봉한다. 선택한 항목을 사용자 데이터의 `widgets/` 설치 공간에 `manifest.json`으로 작성·검증·등록하며 네트워크에서 기능 코드를 내려받지 않는다. IPC snapshot의 `packageBytes`는 **manifest 파일 크기**이며 현재 관리 화면에는 표시하지 않는다. 실행 코드·화면·실행 메모리의 크기를 뜻하지 않는다.

22개 기능과 화면은 앱의 공용 Rust 호스트와 프론트엔드에 컴파일되어 있다. 제거하면 등록·manifest·작업을 정리하지만 앱 실행 파일 크기는 줄지 않는다. 비활성·미설치 도구의 작업은 실행하지 않는다. 원격 배포 주소·서명·자동 업데이트 서비스는 아직 제공하지 않는다.

후속 외부 패키지 설치의 목표는 앱 재빌드나 사용자 기기의 Rust 컴파일 없이 설치하는 것이다. 현재 외부 ZIP 설치기는 제공하지 않는다. ZIP과 manifest만으로 임의의 기능이 실행되는 것은 아니다. 지원할 선언적 동작·외부 연결·선택적 코드 실행 범위는 [위젯 작성 안내](authoring.md)의 미정 사항을 해결한 뒤 공개한다.

설치는 임시 공간에서 검사한 뒤 완료 상태를 반영한다. 중간 실패가 기존 설치나 사용자 데이터를 훼손하지 않아야 한다. 업데이트 실패 시 검증된 이전 설치를 유지하고, 늘어난 권한은 사용자가 선택하기 전 활성화하지 않는다.

## 인수 조건

- 위젯을 하나도 선택하지 않고 A/B의 인사·수다·단어장을 사용할 수 있다.
- 선택하지 않은 위젯이 설치·실행되지 않으며, 선택한 항목만 재시작 후 유지된다.
- 추가 설치·끄기·제거·재설치를 같은 관리 흐름에서 수행한다.
- 설치 실패를 설치 완료로 표시하지 않고 재시도해도 중복 설치하지 않는다.
- 끄기·제거 뒤 예약과 준비 대사가 되살아나지 않는다.
- 제거 후 투두와 준비물 등 보존 대상 데이터가 남고, 의존 기능의 상태가 설명된다.
- 앱 업데이트가 제거한 위젯을 복원하지 않는다.
- 위젯 0개·켜짐·꺼짐·화면 닫힘에서 자원 사용을 비교하고, 선택 설치가 곧 실행 파일 크기 감소라고 안내하지 않는다.

초기 설정 위치, 공식 배포 경로, 데이터 삭제 범위나 의존성 정책이 바뀌면 이 문서와 카탈로그·상태표를 함께 갱신한다.
