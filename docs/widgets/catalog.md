# 위젯 전체 카탈로그

기준일: 2026-09-15. Comet의 놀이·생활 기능을 설치 단위로 정리한 기준 목록이다. 기능 상세는 [장난감](../product/toys.md)과 [할 일·캘린더](../product/planning.md), 후속 작업은 [로드맵](../development/roadmap.md)을 따른다. 실행 가능한 공식 목록의 원본은 `widgets/catalog.json`이며 검증 범위는 [위젯 검증 기록](../VALIDATION-WIDGETS.md)에 둔다.

| 결정 수준 | 내용 |
| --- | --- |
| 사용자 확정 요구 | 처음에 원하는 위젯만 선택하고, 모두 건너뛸 수 있다. 이후에도 추가 설치·제거할 수 있어야 한다. |
| 공식 패키지 경계 | 아래 22개 선택 묶음을 동봉 manifest와 공용 호스트 기능으로 구현했다. 외부 패키지를 실행하는 공개 SDK와는 별개다. |
| 구현 상태 | 22개 공식 도구의 화면·명령·상태 저장과 선택 설치 관리가 소스에 있다. 플랫폼·외부 계정의 실제 검증 범위는 별도 기록한다. |

전체 패키지 목록은 이 문서에서 관리한다. [설치와 관리](installation.md)는 첫 선택·추가·제거의 사용자 흐름을 다룬다. 항목 번호는 목록 확인용이며 영구 패키지 식별자가 아니다.

## 기본 본체와 선택 기능

[캐릭터팩](../product/characters.md)은 캐릭터 교체·공유를 위한 별도 콘텐츠 유형이며 아래 22개 도구 패키지 수에 포함하지 않는다. 캐릭터팩 설치가 위젯을 자동 설치하지 않는다.

0.2에 구현된 작은 A/B 본체, 내장 수다, 일시 말풍선, 직접 입력, 단어장, 기록·기억·친밀도는 기본 경험이다. 위젯을 하나도 설치하지 않아도 모델·계정 없이 이 경험이 동작해야 한다. 설치 관리는 기본 본체에서 여는 보조 화면으로 제공한다.

위젯을 설치했다고 바탕화면에 큰 관리 대시보드를 상시 표시하지 않는다. 캐릭터 메뉴에서 필요한 기능을 꺼내 쓰고 정리한다. 설치 여부와 현재 화면에 꺼내 놓았는지는 구분한다.

LLM과 모델 다운로드는 별도 선택이다. 현재 Qwen3.5-4B 기본·9B 선택을 유지하며 어느 위젯도 모델 다운로드를 필수 조건으로 삼지 않는다. 등록 대사와 실제 도구 상태만으로 반응할 수 있어야 한다. 선택적인 LLM 표현은 [대화 규칙](../product/conversation.md)을 따른다.

## 공통 브리핑은 별도 패키지가 아니다 (후속 보기 제안)

오늘 브리핑은 설치된 할 일·캘린더의 상태를 모아 보여 주는 공통 보기로 제안한다. 할 일만 있으면 할 일만, 캘린더만 있으면 조회한 일정만 보여 준다. 어느 쪽도 없으면 설치를 강요하지 않는다. 브리핑 때문에 다른 패키지를 자동 설치하거나 연결하지 않는다.

사용자가 요청하는 보기를 기본으로 두고 자동 브리핑은 별도 선택으로 다룬다. 통합 브리핑은 아직 별도 구현하지 않았다. 현재 할 일의 오늘 보기와 캘린더의 오늘·다음 일정 보기를 제공한다. 일정 알림의 실제 기본값은 [할 일·캘린더](../product/planning.md)를 따른다.

## 의존성과 제거의 경계

패키지 의존성이 사용자 작성 데이터의 소유권을 바꾸지는 않는다. 예를 들어 캘린더 제거로 준비 봉투의 일정 연결을 사용할 수 없게 되더라도 로컬 체크리스트·자료를 조용히 삭제하지 않는다. 할 일 제거로 완료 구슬병의 새 반응이 중단돼도 기록을 완료되지 않은 상태로 조작하지 않는다.

필수 패키지 설치·제거 시 영향을 미리 보여 주고, 선택 연동은 상대 패키지가 없어도 정상적인 상태로 설명한다. 숨은 연쇄 설치·연쇄 데이터 삭제는 하지 않는다. 비활성화·제거·재설치와 데이터 보존 선택의 상세는 [설치와 관리](installation.md), 작업·대기 대사 취소는 [수명주기](lifecycle.md)를 따른다.

## 구현할 때 확인할 조건

- 첫 선택을 모두 건너뛰어도 기본 A/B 경험이 시작된다.
- 같은 카탈로그에서 나중에 추가·제거할 수 있고, 설치하지 않은 기능을 사용 가능한 기능으로 표시하지 않는다.
- 필수 의존성과 선택 연동을 구분하며, 외부 연결 실패가 무관한 로컬 도구를 막지 않는다.
- LLM 없이 도구 조작과 등록 대사 반응이 동작한다. 타이머 종료·캐릭터 자율 놀이를 할 일 완료 권한으로 해석하지 않는다.
- 제거한 도구의 작업·대사가 뒤늦게 돌아오지 않고, 기본 단어장·기록·기억·친밀도를 보존한다.
- 패키지 묶음을 바꾸면 이 목록과 설치 안내·로드맵을 함께 갱신한다. 구현 완료는 실제 검증 후 [상태 문서](../status.md)에 기록한다.
