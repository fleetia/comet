# comet

바탕화면의 작은 캐릭터와 잠깐 나타나는 말풍선을 중심으로 하는 데스크톱 앱입니다.

완성 후 위키를 만들기 전까지 제품 사양·개발 절차·검증 기록의 원본은 Fleet 한 곳에서 관리합니다. 문서 원본이 갈리지 않도록 저장소 문서와 문서 사이트를 임시로 제거했습니다.
