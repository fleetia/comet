## 0.1.0

### Minor Changes

- f45a785: 기존 앱을 apps/comet으로 분리하고 Figma 기반 아이콘·Light/Dark 토큰·공통 UI와 Storybook을 내부 모노레포 패키지로 제공한다.
- f9bb66a: 바탕화면 위젯 편집을 가짜 바탕화면 창 대신 실제 위젯 창의 제자리 편집과 작은 편집 패널로 바꿉니다. 끌어 옮긴 위치를 화면 좌표로 저장하고 격자·다른 위젯 맞춤을 적용하며, 앱을 다시 시작하면 놓아 둔 위젯을 복원합니다.

  위젯 설정은 즉시 저장하고 미리보기는 실제 바탕화면 위젯과 같은 렌더러를 씁니다. 모아두기는 Figma에 맞춰 행 간격·펼침·편집 모양을 정리하고 위젯 뒤의 어두운 그림자를 없앱니다. 디자인 시스템에서 앱 전용 위젯 종류와 문구를 걷어 내고 위젯 색상 토큰을 추가합니다.

### Patch Changes

- 4089f21: Figma의 전체 개편안을 내재화한 디자인 시스템으로 구현합니다. 친구·설정·대화·빠른 실행·다이어리·집중·위젯 화면을 새 구성으로 연결하고 기존 저장, 초안, 취소 및 데이터 경계를 유지합니다.

  바탕화면에서 글자를 선명하게 읽을 수 있도록 앱 표면과 기본 시계·날씨 위젯의 배경을 불투명하게 표시합니다.

  궤도 메뉴 안의 복제 캐릭터를 제거하고 실제 바탕화면 본체를 기준으로 메뉴와 연결선을 배치합니다.

  중앙 버튼이 캐릭터에서 먼저 나온 뒤 왼쪽부터 메뉴가 순서대로 펼쳐집니다. 서브메뉴는 메인을 유지한 채 선택한 버튼에서 새 궤도로 뻗으며, 닫을 때는 자식부터 역순으로 접힙니다. 상단 경로 안내와 라벨 배경은 제거하고 글자 외곽선과 그림자로 가독성을 높입니다.

- 집중 타이머의 상태별 화면·설정 미리보기와 준비 봉투의 생성·상세·설정을 연결합니다. 실제 집중 구간과 시간표 표시 선택, 완료 메모의 저장 충돌 보호, 봉투와 템플릿 할 일의 중복 없는 생성을 지원합니다.

  봉투 저장 전 거절은 초안을 유지하며 편집을 다시 허용하고, 응답이 불명확하면 같은 요청으로 결과를 복구합니다. 완료한 할 일의 중복 처리와 절전 복귀 뒤 지난 알림·새 휴식 생성을 막고, 최근 다이어리의 수동 시간 기록과 키보드 탐색을 유지합니다.
