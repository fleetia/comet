# Comet 디자인 시스템

기준 디자인은 [Comet Figma 파일](https://www.figma.com/design/aWNznF6uo5AlqF0YokiXZY)입니다.

왼쪽의 **Foundations**에서 토큰 전체를 검색하고 두 색상 모드를 비교할 수 있습니다. **Motion**에서는 움직임 곡선·길이·크기를 확인하고 등장·퇴장, 차례로 나타나기와 움직임 줄이기를 조작합니다. **Icon**에서는 아이콘 전체를 검색하거나 크기와 접근 가능한 이름을 조절합니다. **UI**의 각 컴포넌트에는 사용 안내, Props 표, 조절 가능한 기본 예제와 상태별 예제가 있습니다.

상단 **색상 모드** 메뉴는 현재 예제의 `data-comet-theme`를 바꿉니다. Storybook의 기본 밝은 Canvas에 맞춰 처음에는 Light 모드를 사용합니다. 토큰 모드 전환은 Canvas 배경을 변경하지 않으며, 어두운 배경이 필요하면 Storybook 기본 Backgrounds 도구로 선택합니다. UI 컴포넌트의 폰트는 토큰의 IBM Plex Sans KR을 사용하며, 설치되어 있지 않으면 시스템 sans-serif로 표시합니다. 이 카탈로그는 외부 웹 폰트를 자동 다운로드하지 않습니다.

예제에 공통 배경이나 장식용 컨테이너를 추가하지 않으며, Canvas는 Storybook 기본 설정을 사용합니다. 배경은 Surface 컴포넌트나 색상 토큰 미리보기처럼 예제 자체에 필요한 경우에만 표시합니다.

상단 **움직임** 메뉴는 운영체제 설정을 따르거나 카탈로그 전체에 움직임 줄이기를 적용합니다. 운영체제에서 움직임을 줄였다면 카탈로그에서도 애니메이션과 전환이 꺼집니다. 앱에서는 `ThemeRoot motion="reduced"`로 원하는 영역에 같은 설정을 적용할 수 있습니다. 기다림 점은 멈춘 상태에서도 세 개 모두 보여 진행 중임을 표시합니다.

## 패키지 사용

소스 패키지를 소비하는 워크스페이스에서 `workspace:*` 의존성을 선언합니다. UI는 vanilla-extract를 사용하므로 소비 환경에 해당 변환 플러그인이 필요합니다. Storybook은 자체 Vite 설정으로 이 플러그인을 연결합니다.

```tsx
import "@comet/token/styles.css";
import { Button } from "@comet/ui";
import { BellIcon } from "@comet/icon";

export function Example() {
  return (
    <div data-comet-theme="dark">
      <Button>
        <BellIcon />
        알림 확인
      </Button>
    </div>
  );
}
```

## 입력과 접근성

- Button은 기본적으로 폼을 제출하지 않습니다. 제출 동작에는 `type="submit"`을 명시합니다.
- 아이콘만 있는 버튼에는 `aria-label`을 제공합니다. 보이는 텍스트가 있으면 아이콘은 장식용으로 유지합니다.
- 텍스트 입력·선택·슬라이더에는 연결된 label이나 `aria-label`이 필요합니다. placeholder는 label을 대신하지 않습니다.
- Checkbox·Radio·Switch·Slider는 native 입력 동작을 사용합니다. Tab으로 이동한 뒤 Space 또는 방향키로 조절할 수 있습니다.
- disabled는 실제 입력을 비활성화합니다. 읽기 전용 값은 지원되는 입력의 readOnly를 사용합니다.

각 UI 예제의 사용 안내에서 상태와 키보드 동작을 확인하세요. Figma의 샘플 문구나 프로토타입 상태변수는 앱의 전역 상태로 가져오지 않습니다. 값과 변경 처리는 소비자가 소유합니다.

## 실행

저장소 루트에서 다음 명령으로 Storybook을 시작할 수 있습니다.

```sh
corepack pnpm --filter @comet/storybook dev
```

앱 코드와 Storybook은 별도 패키지입니다. 카탈로그 추가만으로 Comet 앱이 이 UI를 사용하게 되지는 않습니다.
